## 二、TTS 静音口径（重要）

v0.08 虽把「🗣️ 自动朗读」默认设为关，但存在一条绕过开关的链路：

```js
// v0.08（有问题）
function toast(m){ ...; speak(m,true); ... }        // force=true 无视 speakOn
function announce(m){ ...; if(!booting)speak(m) }   // 无条件跟随
```

任何提示条（切天气 `toast('🌤 '+WX_NAME[v])`、答题通关、切全屏…）都会调用系统 TTS 念出文字。用户听到的「自动播报」不是天气音，而是念「天晴 · 鸟叫」这几个字。

v0.09：

```js
function toast(m){ ...; /* 无 TTS */ ... }
function announce(m){ ...; if(!booting && speakOn) speak(m) }
```

- **朗读关闭 = 零 TTS**；只有用户主动点「🔁 朗读本句」（`speak(text,true)`，force 保留给用户手势）或开启「🗣️ 自动朗读」才会发声；
- **盲人友好不受损**：`#live`（`aria-live="polite"`）与 `#alert`（`role="status"`）仍写入文字，读屏软件自行播报，不与系统 TTS 抢音频通道；
- **天气音不受影响**：鸟叫 / 雨声 / 虫鸣 / 风声是 Web Audio 振荡器与噪声缓冲实时合成，属用户想听的环境音，不是 TTS。

验收方式：在页面加载前 Hook `speechSynthesis.speak` 计数，跑完整链路「切天气 → 剧情 → 对白 → 选项 → 答题 → 全屏 → 10 页回归」，**触发 0 次**；同时确认 `AE.amb.alive=true / type=sunny`、晴天画布 61,804 个非透明像素。

## 三、选项不遮挡的几何口径

v0.08 的选项气泡 `width:52%` 且**没有 `max-height`**，四个长选项竖排把气泡从 `bottom:5%` 一路撑到画面顶部，HUD、角色、顶部工具按钮全被压住。

v0.09 `.mode-choice`：

| 属性 | 值 | 作用 |
|---|---|---|
| `width` | 57%（≤820px 时 64–68%） | 与右侧角色分区留出间隙 |
| `max-height` | 37%（小屏 42%） | 绝不顶到 HUD |
| `overflow-y` | auto | 超长选项 / 反馈文字内部滚动 |
| `.vn-choices` | `grid-template-columns:1fr 1fr` | 4 选项变 2 行（小屏 1 列） |
| `.vn-name` | `position:static` | 名牌不再被 overflow 裁掉半截 |
| `.vn-corner` | 移除 | 右下角浮动按钮不再压角色脚 |

浏览器实测（1280×900）：

```
overlapHUD   = false
overlapChar  = false
gapChar      = 26px      （气泡右缘与角色左缘）
nameInside   = true
dialogInStage= true
```

所有立绘仍 `object-fit:contain`，boundingRect 完整落在舞台内。

## 四、全屏 / 横屏

- `goFull()`：从 `$$('.vn,.stage')` 里挑**当前可见**面板（`!x.closest('.panel[hidden]')`），`requestFullscreen()` 成功后尝试 `screen.orientation.lock('landscape')`（`catch` 吞掉不支持的浏览器）；
- 入口 3 处：工具栏 `#fullBtn`（金色）、对白气泡工具行、选项气泡工具行；语音说「全屏 / 横屏」通过包装 `handleVoice` 生效；`Esc` 或再点按钮退出；
- CSS `.vn:fullscreen, .stage:fullscreen` → `100vw × 100vh`、`aspect-ratio:auto`、去圆角；气泡 `max-width:56vw`；
- 竖屏手机（`@media (orientation:portrait) and (max-width:820px)`）HUD 显示「📱 建议横屏 · 点 ⛶ 全屏」；
- **边界**：Fullscreen API 与 `orientation.lock` 受浏览器 / 系统限制，iOS 与部分桌面浏览器可能只能全屏不能强制旋转，此时按提示手动旋转设备；已在 README 与页面如实说明。
