## 一、你提的三个问题，根因和修法

### 1️⃣ 「点天气预览听下，怎么会自动播报声音」

**根因**：`toast()` 里写死了 `speak(m, true)` —— `force=true` 直接绕过朗读开关。所以哪怕「🗣️ 自动朗读」是关的，任何提示条（切天气、答对通关、切全屏…）都会用系统 TTS 念出来。第二张截图里选项画面也在念，是同一条链路。`announce()` 也无条件跟着念。

**修法**：
- `toast()` 改成**纯视觉**，删掉强制 TTS；
- `announce()` 改成 `if(!booting && speakOn)` 才发声；
- 现在**朗读关闭 = 全站零语音播报**，只有你主动点「🔁 朗读本句」或开启自动朗读才有 TTS；
- 盲人友好不受影响：`#live` / `#alert` 的 `aria-live` 仍会把文字交给读屏软件，由读屏自行播报，不与 TTS 抢通道。

> 你点天气想听的是**鸟叫 / 雨声**，那是 Web Audio 合成的场景音，不是 TTS，保留且正常响。实测：切晴天 → TTS 触发 **0 次**，环境音 `alive=true / sunny`，晴天猫画布 61,804 个非透明像素。

### 2️⃣ 「这个主页好丑啊」

截图里的问题：满屏三角 / 菱形符文底纹、标题与副标题换行散乱、状态徽章东一个西一个。

**修法**：
- `#bgArt` 的三角与菱形**全部移除**，只留极淡圆点阵（透明度 0.30 → 0.10）；
- 换成**杂志封面式 `.masthead`**：左侧金边头像 + 英文小 kicker + 单行主标题（副标题缩成一句）+ 金色竖线；右侧一整块 `VERSION / 关卡进度 / 已解锁词条 / 当前难度` 状态板，等宽对齐、数字用等宽字形；
- 开场三步玩法改成 3 张编号卡，去掉大块警示框改一行脚注；难度下拉文字缩短，不再被截断；
- 工具栏统一圆角与分组色，新增金色「⛶ 全屏 / 横屏」。

### 3️⃣ 「画面基本遮挡了，也没有横屏按键」

**根因**：选项阶段 4 个长选项竖排在 `width:52%` 的气泡里，气泡**没有限高**，从底部一直长到顶部 → 盖住 HUD、把角色压成半张脸、顶部「读图卡 / 重看对白」按钮被裁出画面。

**修法**：
- 选项 / 反馈阶段气泡切 `.mode-choice`：`width:57%`、`max-height:37%`、`overflow-y:auto`、四个选项 **2 列网格**、字号收紧；
- 说话人名牌从绝对定位改成**气泡内一行**，不再被 `overflow` 裁掉半截；
- 实测几何：`overlapHUD=false`、`overlapChar=false`、气泡与角色**留 26px 间隙**、名牌完整在气泡内、气泡完全在舞台内；
- 右下角浮动按钮**取消**（原来会压到角色脚），全屏入口改放气泡工具行；
- **新增全屏 / 横屏**：工具栏金色 `#fullBtn` + 对白气泡工具行 + 选项气泡工具行，三处均可点；调用 `requestFullscreen()` 并尝试 `screen.orientation.lock('landscape')`；全屏 CSS 让舞台铺满视口；竖屏手机 HUD 显示「📱 建议横屏 · 点 ⛶ 全屏」；语音说「全屏 / 横屏」也生效。

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.09.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.09.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」→ 点画面 / 空格 / 「下一句 ▶」推进对白 → 「⏭ 跳到选项」→ 四选一。
3. 「🌤 场景」切天气试听鸟叫 / 雨声；「⛶ 全屏 / 横屏」放大舞台；`Esc` 退出全屏。
4. 音频受浏览器策略限制，首次点按任意处后场景音才响；「🔊 音效」是总开关。

**朗读**：默认关，不会自动出声；想听点 🗣 开自动朗读，或点「🔁 朗读本句」单独读当前对白 / 本页摘要，「⏹ 停止」随时掐断。
