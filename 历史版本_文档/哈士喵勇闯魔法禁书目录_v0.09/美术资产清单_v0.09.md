## 四、代码生成的视觉元素（无图片文件）

| 元素 | 生成方式 |
|---|---|
| 杂志封面式 masthead | CSS 渐变 / 金色竖线 / 头像金边 / 状态板等宽数字 |
| 背景点阵 | SVG pattern（v0.09 已移除三角与菱形，只留圆点，opacity 0.10） |
| 三步编号卡 | CSS grid + 序号样式 |
| AVG 气泡 / 选项横条 | CSS 圆角 + 名牌内嵌 + 2 列网格 + 限高滚动 |
| 7 种天气 | Canvas 2D 粒子系统，逐帧 `requestAnimationFrame` |
| 场景音效 | Web Audio 振荡器 + 噪声缓冲实时合成 |
| 关卡立绘排位 | `CAST_MAP` 按 30 关取 1–3 个已有透明层，主 / 副错位 |
| 全屏 / 横屏 | Fullscreen API + `screen.orientation.lock('landscape')` |

**角色不裁剪的 CSS 口径**：`.vn-char` / `.stage-char` / `.char-btn img` / `.roster img` 一律 `object-fit:contain`、`object-position:bottom center`；只有 `.vn-bg` / `.stage-bg` 背景板用 `cover`。选项气泡 `width:57%` 靠左、角色 `right:2%` 靠右，实测间隙 26px，零重叠。
