## 〇、人格测试为什么完全点不动

**是真 bug，不是样式盖住。** `answerQuiz()` 里写了：

```js
qs[a[1]]++; qh.push({q:q, a:a[0], t:a[1]});
```

`q` 只是 `renderQuiz()` 里的局部 `const`，`answerQuiz()` 里根本不存在，所以每次点击都抛 `ReferenceError: q is not defined`，题号永远停在 1/16。已改为 `DATA.quiz[qi].q`。

修的过程中还挖出**两个连带的启动期崩溃**：

| 根因 | 表现 | 修复 |
|---|---|---|
| `perfLocked` 是后定义的 `const` 箭头函数，`renderMap()` 在启动早期调用它 | `Cannot access 'perfLocked' before initialization` | 改成函数声明（提升） |
| `PERF_READY` / `SCENE_MAP` / `QUEST_FRAME` / `EXPR_QUESTS` 是脚本后段的 `const`，启动末尾 `renderAll()` 触发 TDZ | `Cannot access 'PERF_READY' before initialization`，整段初始化中断 → 人格测试 / 地图 / 关于页全空白 | 四个常量前置到 `<script>` 开头 |

这三层都修完后，实测**真点击 16 题一路到结果页**（`qi=16`、`qh.length=16`、结果「🫶 羁绊守护型」），重测能重置回 4 个选项；桌面与手机都能点。

## 一、这轮做了什么

### 1️⃣ 关卡地图：矮卡 + 已完成折叠到底部

- 原来的 `.node` 有 `min-height:138px`，30 关加上 6 个章节标题，手机上要滚很久。现在卡片高度自适应、双列网格、出处小字单行省略、标签缩小；
- **已通关关卡不再混在列表里**：统一收进页面最底部的 `<details>`「✅ 已完成 N / 30 关 · 点击展开回看」，默认收起，展开才显示紧凑已通关卡片；
- 顶部与新说明重复的旧段落删掉，只留一行「按故事先后分六章 · 点关卡进入 AVG 舞台 · 通关解锁词条」；
- 实测桌面地图 **1206px**、手机 **2018px**（两列 173px），已完成 3 关时折叠区默认收起、展开恰好 3 张且全部标「已通关」。

### 2️⃣ 名牌紧贴气泡，横屏不再挡对白

你说「导览员的那个气泡应该紧贴下面那个气泡」——原来名牌是 `position:absolute; top:-17px` 浮在气泡上方，还带一个 `::before` 小尖角，视觉上分家；伪横屏旋转 90° 后，这块名牌正好压在对白文字左侧。

现在把**名牌收进气泡内第一行**（`position:static; inline-block`，与文字零距离），隐藏小尖角；横屏气泡再降到 20% 底、取消 `backdrop-filter` 模糊。实测名牌 `position=static`、尖角 `display=none`、`#vnDialog.contains(.vn-name)=true`，桌面 / 手机 / 横屏一致。

### 3️⃣ 竖屏天气不再挡角色，小角色下移放大

竖屏 HUD 原来折成三行，第三行「📱 竖屏建议点 ⛶ 横屏」正好压在左上角副角色头上，天气标签也挤在旁边。现在：

- 竖屏 HUD 强制**单行**，隐藏卷次/剧透行与「竖屏建议」提示（工具栏已有横屏按钮），天气缩到右上角；
- 副角色 `top: 8% → 20%`、`height: 34% → 42%`、`max-width: 32%`，明显下移放大；
- 实测可见 HUD 只剩「章节」+「天气」两个标签，**与副角色重叠 0 项**。

### 4️⃣ 每轮固定生成素材（不用提醒，本轮也做了）

按硬规则挑第 10–12 关的缺口并生成：

| 场景 | 横版 1600×900 | 竖版 900×1600 |
|---|---|---|
| 英国清教前线 · 石板回廊 | ✅ | ✅ |
| 右方之火战线 · 燃烧废墟 | ✅ | ✅ |
| 白翼挡炮 · 夜空炮击 | ✅ | ✅ |

- **6 张生成原图 → 6 张可用场景板**，画内无角色；火焰、炮击光带、展开白翼**全部画进场景板**，角色层仍保持闭合实心剪影；
- 右下角「元宝 AI 生成」水印用 inpaint 抹掉，含水印原图与去水印 WebP 一并随包；WebP q78，单张 92–225 KB；
- `SCENE_MAP` / `QUEST_FRAME` 接入第 10–12 关，`PERF_READY=[1..12]`，**第 10–12 关解锁**，锁关 **21 → 18**；累计 **9 组横竖场景板**。
