# 呼吸感与表演素材生成计划 · v0.29

## 本轮（每轮第一件事）
1. 先生成 2 张：黄昏街角场景板（Image2Image / 现有阳台板基准）、三角色 4:5 改排卡（Image2Image / 三定稿并排图基准）
2. 场景板去水印进网页；改排卡**漏了神裂 + 比例没生效 → 否决留档**
3. 正式完整卡改用三张定稿层确定性拼版（三只都在、零裁切），进网页
4. 顺带完成三角色裁切感的根因排查与 CSS 修复

## 一致性复盘
连续几轮证明：**多主体改排 / 自由发挥**最容易漂移或漏主体。
本轮改排稿漏了神裂，正好撞在用户点名的三个角色上，所以直接否决。
→ 规则升级：**多角色合成一律用定稿层确定性拼版**，AI 只用于「以单张已有资产为基准、改动范围小」的图。

## 硬规则
1. 每轮先补素材，不等提醒
2. 角色只在 21 张定稿基准上做差分，禁止整批重画
3. 新层：纯品红幕、实心闭合、`binary_fill_holes` 孔洞 0、无水印
4. 生成稿先比对基准，漂移即否决留档；至少一张真生成稿进网页
5. 用户明确否决的稿不补同款
6. 缺素材关卡先锁「敬请期待」，登记缺口但不假装完成
