## 本轮做了什么
- **角色全部回归定稿**：把你认可的 v0.06 那批 21 张定稿层登记为唯一基准，把 17 个被自行重抠层占用的表情覆盖键全部回退。展柜与剧情关卡现在用同一张图。
- **品红底 / 黑底方块消失**：上一轮自行重抠的两层没抠干净（品红半幅带水印、黑底小方块）并覆盖了定稿，本轮清除。全量扫描 131 张内嵌图，疑似品红底 / 黑底方块 **0 张**。
- **竖屏场景真正露出**：查到 `.vn-bg` 一直是 `display:none`，历轮调亮度 / contain 都无效。本轮让竖屏舞台内场景板真正显示，阳台夕阳、自动贩卖机、栏杆盆栽都能在气泡后半透看到。
- 作者原稿按钮全站 0 个；朗读默认关；四选项竖屏 / 横屏 4/4 可见。

## 操作
- 剧情页「🖼 看全场景」＝纯净场景开关，再点一次回来
- 「⛶ 横屏」＝ CSS 伪横屏，需手动把手机横过来；方向反了点「↻ 换个方向」
- 设置浮层：气泡透明度、音量、震动反馈、角色缩放都可调；✕ / Esc / 点遮罩都能关
- 展柜缩略图点开可拖动、缩放、⛶ 全屏

## 版本规则
`v0.01` 起每轮 +0.01；每轮第一件事补美术资源；交付含游戏 HTML + md 文档 + zip + 版本号。
