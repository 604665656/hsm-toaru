## 一、这轮做了什么

### 1️⃣ 背景全屏，不论横屏竖屏

- **默认开启**全屏背景，不用再点按钮；竖屏载入 **1152×2048 竖版**、桌面横屏载入 **2048×1152 横版**，`object-fit:cover` 铺满整个视口；
- **伪横屏时 `#fullBg` 也跟着 `rotate(90deg)`**，横过手机之后背景仍铺满，不会变成竖图被裁的一条；`↻ 换个方向` 同步翻转；
- 按关卡自动换场景：第 1 关阳台夜、第 2 关三泽塾、第 3 关河边实验场，其余回落阳台；`resize` / `orientationchange` / 切关都会重新取图；
- 主行「🖼 背景：开」仍可一键关掉，关掉后舞台内恢复原来的 16:9 背景。

### 2️⃣ 给人物上半身更多空间（按你纠正的做法）

你明确说：**不是上半身特写**，而是「气泡不是透明的吗，需要全身就全身，需要半身就下半身在气泡，凸显上半身」。所以这版：

- 新增 **全身 / 半身两种构图**，按场景自动选：第 1–3 关对话戏用 `half`，其余用 `full`；设置里可手动切「自动 / 全身 / 半身」；
- 半身构图＝角色整体放大、**贴容器顶部**，下半身自然延伸到半透明气泡与控制条后面；因为气泡透明度降到 `.30/.38`、控制条降到 `.40/.48`，下半身能透出来，视觉上上半身被凸显；
- 手机竖屏把角色容器放宽到 88%，避免 `object-fit:contain` 被窄宽度限制把猫压到画面底部（这轮实测修掉了「只露出两只耳朵」的问题）；
- 实测：桌面 / 手机 / 伪横屏三态角色头顶都在舞台 **8%** 处，`headVisible=true`，四选项仍 4/4 可见；全身构图选项阶段不压角色。

### 3️⃣ 气泡更透、更小

| 项 | v0.11 | v0.12 |
|---|---|---|
| 玻璃底 | `rgba(.58/.66)` | **`rgba(.30/.38)`** |
| 模糊 | `blur(11px)` | `blur(5px)` |
| 对白气泡宽 | 52% | **44%** |
| 题干胶囊宽 | 58% | **46%** |
| padding | 13px | 9px |
| 选项控制条 | `.60/.70` | **`.40/.48`** |

文字加三层投影保可读；题干文案缩成「选出正确项」，手机上一行放得下。

### 4️⃣ 设置：能藏就藏，要展开也顺手

- 主行只留 **4 项**：⚙ 设置 / 🌤 场景 / ⛶ 横屏 / 🖼 背景；音效、音乐、朗读、语音控制、朗读本句、停止、剧透、限时、重玩、语音包、文字导览、更多页面、角色构图全部收进**独立设置浮层**；
- 浮层有 **右上角大红 ✕** + **底部通栏「✕ 关闭设置」** + `Esc` + 点遮罩，四种方式都能关；
- 内容太长可**滚动**（手机实测 `825 > 574`），标题栏可**拖动**（实测位移 −140 / +42 px），支持触摸；
- 分组：声音 / 画面与构图 / 玩法与无障碍。

### 5️⃣ 首页那个丑猫头去掉了

原来 masthead 里的 `<svg>` 猫头不是图生图的，按你的意见**直接移除**，改成纯文字标题 + 4 格状态板。本轮生成的 1:1 头像特写按「不用上半身特写」**留档但不采用、不进网页**，文件在 `美术资产/头像候选_未采用/`。

### 6️⃣ 本轮顺手补了素材（延续「缺就生成」）

| 生成原图 | 张数 | 产物 |
|---|---|---|
| 三泽塾废弃教室场景板 横 / 竖 | 2 | 2 张去水印 WebP（256.8 / 235.1 KB） |
| 河边实验场场景板 横 / 竖 | 2 | 2 张去水印 WebP（153.0 / 188.7 KB） |
| 美琴＋一方通行 吸 / 呼 品红幕合页 | 2 | 4 个透明呼吸层 |
| 史提尔＋右方之火 吸 / 呼 品红幕合页 | 2 | 4 个透明呼吸层 |
| 1:1 头像特写 | 1 | **未采用**，仅留档 |

- 合计 **9 张生成原图 → 8 个新透明层 + 4 张场景板**，全部内嵌网页；
- 8 个新呼吸层 `alpha_holes` **全部 = 0**，大凹陷 / 品红残留均达标，亮青底目检无溢边；
- **有真图呼吸帧的角色从 4 个扩到 8 个**（+ 美琴 / 一方通行 / 史提尔 / 右方之火）；
- 火焰／炼金阵、蓝白电弧**都画进场景板里**，角色层仍是闭合剪影，不重犯开口缝缺块；
- **第 2、3 关已从「敬请期待」解锁**，锁关从 29 降到 27。

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.12.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.12.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」玩第 1–3 关；其余显示「敬请期待」。
3. 「⚙ 设置」里切角色构图、开文字导览、导入语音包、展开更多页面；右上 ✕ 或底部大按钮或 `Esc` 关闭。
4. 「⛶ 横屏」把舞台和背景一起横过来；「🖼 背景：开」可关掉全屏背景。
5. 朗读默认关，不会自动出声；「🗣️ 自动朗读」在设置里。
