## 四、代码生成的视觉元素（无图片文件）

| 元素 | 生成方式 |
|---|---|
| 双帧呼吸 | `.vn-actor` 两 `<img>` + `breathA` / `breathB` 3.4s 交错 opacity / transform |
| CSS 呼吸兜底 | `.breathe-css` 3.4s `translateY(-4px) scale(1.012)` |
| 全屏背景 | `#fullBg` `fixed` + `object-fit:cover`，按关卡与方向取 6 张场景板之一；伪横屏跟着 `rotate(±90deg)` |
| 半身 / 全身构图 | `frame-half` 贴顶放大（下半身没入半透气泡）/ `frame-full` 完整贴底 |
| CSS 伪横屏 | `fixed` + `100dvh×100dvw` + `rotate(±90deg)`；控制条在容器外 |
| 通透玻璃气泡 / 底部 2×2 控制条 | rgba 渐变 + `backdrop-filter:blur(5px)` + grid |
| 7 种天气 | Canvas 2D 粒子系统 |
| 场景音效 / 分角色 TTS | Web Audio 合成 + `SpeechSynthesisUtterance` 的 pitch / rate |

**角色不裁剪口径**：`.vn-char` / `.vn-actor` / `.stage-char` / `.char-btn img` 一律 `object-fit:contain`；`.vn-actor` 必须显式给 `width`（空 span 的 shrink-to-fit 会塌成 0 宽）。半身模式 `object-position:top center`，全身模式 `bottom center`。三态实测头顶均在舞台 8%，`headVisible=true`。
