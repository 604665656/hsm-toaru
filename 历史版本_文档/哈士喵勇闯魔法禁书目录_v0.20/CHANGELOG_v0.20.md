## 版本号规则

- 从 **v0.01** 开始每次交付递增 `0.01`：v0.01 → … → v0.19 → **v0.20**。
- 版本号同时出现在：网页标题 / 状态板 / 页脚、README、CHANGELOG、考据、计划、登记、资产清单、压缩包名。
- 每次交付固定：**游戏 HTML + Markdown 文档 + 压缩包**。
- **v0.20 起**：交付入口只给游戏 HTML 一个文件卡片，不再附门户页 / 文档卡片 / zip 卡片。

## v0.20 — 2026-11-08 · APP 直接预览 / 轻量单文件 / 24–30 关场景板

### 用户反馈

> 「直接给我游戏文件就好了」「你这轮给我的打不开还得下载，先补素材」「APP 里本地 HTML 必然以文件卡片能在 app 里面打开预览就行了」

### ⓪ 第一件事：先补素材

生成 3 组 × 横竖共 **6 张场景板**：最终战场（紫红极光 / 碎石 / 蓝色魔法阵余晖）、学园都市复原（雨后清晨 / 风塔 / 镜面反光）、创约异形街景（哥特书库 × 玻璃幕墙 / 符文光环）。接入 `SCENE_MAP[24..30]`，累计 **42 张场景板（21 组）+ 2 张设定图**，`ASSET_SCENES` 15 → **18 条**。

### ① 打不开还得下载的根因

v0.19 游戏 HTML **11.7 MB**，APP 对大文件只给「下载链接」而非可预览卡片；门户页（iframe 包装）虽小但多一层、还带一堆按钮卡片。用户要的是「一个游戏 HTML 文件卡片，点开即玩」。

修复：
- 移除门户页，只交付游戏 HTML；
- 全部 106 张内嵌图重编码为轻量 WebP（大图长边 720、q50，透明层保留 alpha），**11.7 MB → 3.67 MB**；
- 保持全内嵌、零外部依赖，单独一个文件即可运行；高清素材仍在 zip 内。

### ② 未改动

30 关文本、152 词条、61 时间节点、23 部跨媒体、16 题测试、21 角色层、v0.19 全部交互与存档键原样。只替换 about 页上轮说明卡为 v0.20 卡（含轻量版画质取舍说明）。

### 验收

`node --check` 通过；启动错误 0 / 控制台无报错；106 张图片全部可解码、破图 0；新场景 24 / 26 / 28 / 30 关背景实测载入；拖动、滚轮、震动、长按、布局互斥、⛶ 全屏、原稿覆盖框、音效解锁全部通过；人格测试 16/16、通关卡片、TTS 0、10 页、21 角色卡、手机横屏四选项 4/4。

### 留白
