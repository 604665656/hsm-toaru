## 一、一致性审计与纠偏（每轮第一件事：先补素材）

### 审计方法

以作者更正后的**无水印《眼镜猫·角色三视图》正面**为唯一锚点，对 `ART.chars` 21 层 + `ART.expr` 19 层逐层量化：灰白毛占比、蓝瞳像素占比、暗描边占比、Canny 边缘密度、身比、alpha 孔洞。锚点指标：灰白毛 `0.922`、蓝瞳 `0.0117`、暗描边 `0.033`、边缘密度 `0.0488`、身比 `0.76`、孔洞 `0`。

偏差最大的几项：`char__mugino 1.761` / `expr__kanzaki 1.656` / `char__othinus 1.622` / `char__touma 1.558` / `char__styl 1.415` / `char__shokuhou 1.350` / `char__librarian 1.347`；最一致的：`char__base 0.351` / `expr__alice 0.436` / `char__lastorder 0.466`。完整数据在 `美术资产/一致性审计/角色一致性审计结果.json`，对照图两张随包。

### 纠偏（重要）

审计里「灰白毛占比低」的头号原因其实是**角色穿着深色服装**，我一度把它误判成画风漂移，生成了 5 张「脱衣版」合页（只留灰白猫 + 小道具）。你一句「**衣服没事啊，怎么后面生成的都没衣服，道具根据需求生成**」把方向掰回来了：

> **服装与道具不是画风漂移，是角色辨识度。要统一的是柔和厚涂／彩铅质感、蓝渐变瞳、细圆黑框眼镜、粉腮红、蓬松卷尾、细轮廓线、猫身比例；衣服和道具按角色需求保留。**

## 六、边界（如实说）

- 一致性重画覆盖 **10 个偏差最大的角色层 + 9 个表情层**；`ART.chars` 其余 11 个（本体 / 导览员 / 茵蒂克丝 / 一方 / 最后之作 / 食蜂 / 白井 / 土御门 / 上里 / 去鸣 / 右方之火）与 `ART.expr` 里 4 个（食蜂 / 土御门 / 上里 / 去鸣）仍是旧层，画风与服装保留程度待 v0.23 统一。
- 重画层里的「黑白翼」把翼收拢贴背后，正面几乎看不见翼形，是按你上轮「对称贴背收拢」的要求做的取舍；若想让翼更明显，下轮可改为半展开但仍闭合实心。
- **18 关动画表演未完成**，只锁「敬请期待」不删资料；「参考场景原图重绘」仍缺具体场景原图（你给的是角色三视图定稿）。
- CSS 伪横屏不能强制旋转 iOS 系统方向；`navigator.vibrate` 在 iOS Safari 不可用；语音包仅会话内有效。
- 哈士喵 GitHub / 微信表情包链接仍待提供；创约 14—16 卷沿用 v0.01 边界。
