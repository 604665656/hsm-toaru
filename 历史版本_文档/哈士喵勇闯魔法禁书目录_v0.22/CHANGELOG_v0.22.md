## v0.22 — 2026-11-08 · 原稿按钮全撤 / 竖屏场景修复 / 一致性审计纠偏

### 用户反馈链
> 「还是有作者原画按钮，竖屏几乎看不到场景」 → 「角色一致性检查，按一致性生成」 → 「衣服没事啊，怎么后面生成的都没衣服，道具根据需求生成」

### ⓪ 第一件事：先补素材 + 一致性审计
- 以作者定稿三视图正面为锚点，量化 21 个 `ART.chars` + 19 个 `ART.expr` 的灰白毛 / 蓝瞳 / 暗描边 / 边缘密度 / 身比 / alpha 孔洞；审计结果 JSON 与两张对照图随包。
- **纠偏**：审计曾把「深色服装」误判为画风漂移，生成 5 张脱衣版 → 用户纠正后**全部否决**。按「定稿厚涂画风 + 服装道具按需求保留」重新生成 5 张合页 → **10 个一致性角色层**（上条校服绷带 / 美琴常盘台水手服 / 欧提努斯长袍小书 / 爱丽丝连衣裙扑克 / 馆长披风资料牌 / 麦野制服 / 黑白翼高领 / 滨面马甲工具箱 / 神裂牛仔长刀 / 史提尔修道袍十字架）；另有 **9 个表情层**统一画风。
- 10 层覆盖 `ART.chars` 并与对应 `ART.expr` 完全对齐；9 层注入 `ART.expr`。19 层孔洞 0 / 品红残留 0。

### ① 原稿按钮全撤（上轮漏网）
上轮只清了 `.tabs`，**素材展柜的 `homeTabsV18` / `codexTabsV18` 由 `augmentCase19()` 动态 append 一个 `[data-core]` 按钮**。本轮把 append 条件关掉、全局 DOM 清理 + CSS 隐藏；设置浮层 `#v19Core` 加 `hidden`。10 页实测 0 个可见、0 个 DOM 残留；展柜 tabs 只剩 4 个分类按钮。

### ② 竖屏看不到场景的根因
`exitLandscape()` 旧代码把 `.vn-bg` 强制写成默认星空 `ART.bg`，叠加两层暗角后竖屏只剩深蓝底。修复：`applyStageScene()` 竖屏取本关 `_v` 板、fallback 不再落 `ART.bg`；进/退横屏 / 刷新对白 / resize 都重新套用；竖屏 CSS 背景亮度 1.34、暗角减半、角色缩到 40% 贴顶。「🖼 看全场景」去掉 4.2s 自动恢复，改真开关并排控制行首位。

### 验收
`node --check` 通过；启动错误 0；99 张图片破图 0；原稿按钮 10 页 0 个；19 层孔洞/残留 0、10 个角色 `chars===expr` 全 true；组件重叠 0；人格测试 16/16、通关卡片、TTS 0；手机横屏四选项 4/4、退出后场景板保持；纯净场景 4.6s 后仍保持且可返回。

### 留白
其余 11 个 `ART.chars` 与 4 个 `ART.expr` 旧层待 v0.23 统一；黑白翼收拢后正面翼形不明显；18 关表演仍锁；仍缺具体场景原图；iOS Safari 无 vibrate；伪横屏不强制系统方向。
