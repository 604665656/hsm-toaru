## 二、这版解决的核心问题

你说「图片太笨重了就想办法抠图，背景可以重新成魔禁的画风一致的背景，然后角色就可以在同一个背景下更换了」——v0.04 全部照做：

| v0.03 | v0.04 |
|---|---|
| 一人一整张 2048×1152 图（带米色底、地面线、文字标签） | 角色抠成**透明 WebP 层**，只留人物 |
| 每个角色自带不同背景，切换＝换一整张图 | **1 张共用魔禁画风舞台**，所有角色叠在同一张上 |
| 切换一次约 100 KB 整图 | 切换一次约 **29 KB 透明层**，背景不重载 |
| 5 种形象 | **21 个可切换角色** |
| 128 词条 / 40 条人物词条 | **152 词条 / 64 条人物词条** |

统一舞台：深蓝夜色的学园都市剪影、淡金魔法阵圆环、漂浮的空白魔道书页、左上暖金聚光、浅色石质平台；中央与右侧留出干净的角色站位空间。厚涂绘本笔触 + 暖米色纸本肌理，与角色层画风一致。

### 抠图怎么做的

1. 8 张「双人并排」定妆图，统一**纯色亮绿幕**、无地面线 / 阴影 / 文字 / 标签；每格一个角色，等大不遮挡。
2. 先抹掉右下角平台水印，再按色相与背景色距离提取绿幕候选；**只保留与画面四边连通的绿幕**，角色内部的颜色不会被误抠。
3. 边缘羽化、去绿溢色、形态学补洞；按中间空白列自动切分左右两人，裁出各自包围盒。
4. 输出 420px 高、带 alpha 的 WebP（quality 56）；v0.03 的 5 张旧形态用米色底连通域与 GrabCut 一并抠出。
5. 21 层合计约 **600 KB**、平均 29 KB；共用背景 70 KB。单文件 HTML 约 **1.21 MB**（v0.03 为 1.295 MB，内容却多了 24 条词条与 16 个角色）。
