# 更新日志 · 哈士喵勇闯魔法禁书目录

## 版本号规则

- 从 **v0.01** 开始，每次交付递增 `0.01`：v0.01 → v0.02 → v0.03 → v0.04 …
- 重大重制可跳位（如 v0.10）；同一轮只出一套文件，不覆盖旧版本目录。
- 版本号必须同时出现在：网页标题 / 顶部状态条 / 页脚、README 文件名、CHANGELOG 文件名、资料文档文件名、压缩包文件名。
- 每次交付固定包含：**游戏 HTML + Markdown 文档 + 压缩包**。

### 统一舞台背景

新生成 1 张 16:9 厚涂绘本舞台：深蓝夜色的学园都市剪影（塔楼、风车、发光窗格）、低对比淡金魔法阵圆环、漂浮的空白魔道书页与细符文光带、左上暖金聚光、前景浅色石质平台。中央与右侧留出干净的角色站位空间，不含任何角色、文字、水印。右下角平台水印已做背景修补。

### 抠图流程（可复现，脚本随包）

1. 生成 8 张 16:9「双人并排」定妆图：纯色亮绿幕（约 `#1faa5e`）、无地面线 / 阴影 / 文字 / 标签，每格一个角色、等大不遮挡。
2. 先把右下角平台水印涂成绿幕色；按色相（H 40–100、S>85）与背景色距离提取绿幕候选。
3. **只保留与画面四边连通的绿幕**：角色内部的相似颜色不会被误抠。
4. 边缘高斯羽化、去绿溢色（半透明像素压低 G 通道）、形态学补洞；按中间空白列（左右角色之间的 alpha 谷）自动切分，裁出各自包围盒。
5. 输出 420px 高、带 alpha 的 WebP（quality 56，method 6）。
6. v0.03 的 5 张旧形态另用两套方法抠出：米色底用「颜色距离 + 四边连通域」，导览员深蓝夜色主视觉用 GrabCut 矩形初始化 + 最大连通域。

结果：21 个透明层，叠加到同一舞台后边缘干净、无绿边、无残留背景、无水印。
