## 二、本轮素材（第一件事：先补）

4 张厚涂合页（欧提努斯+爱丽丝 / 上里+去鸣 / 馆长+麦野 / 黑白翼+滨面）+ 1 张黑白翼重画单图 → **8 个透明表情层**。生成端锁死：纯亮品红平涂底、角色身上不得出现品红像素、完全闭合实心剪影（四肢贴身、无指缝腿缝腋下、道具与躯干连成一体、发丝成片不镂空、翼与尾贴背收拢）、不画飘散粒子与半透明、镜片反光不透明浅灰白。

后处理顺序（不可反）：色相键控 → 只保留与四边连通的最大前景域 → `binary_fill_holes` → alpha 内部去色溢 → **硬边二值化**。8 层 `binary_fill_holes(alpha>128) & ~(alpha>128)` 全部 **0**，不透明区品红残留 **0**，亮青底无 halo。

## 三、工程事实

- 「作者原稿不用在上面有按钮」：原实现有两处入口——设置浮层 `#v19Core` 与 `renderGallery` 尾部动态 append 到 `.tabs` 的 `[data-core]` 按钮。本轮 CSS 兜底 + `MutationObserver(.tabs)` 清理，切页后顶部实测 0 个；设置里降级为下划线小字，功能不丢。
- 「页面再紧凑一点」：首次改版手机工具栏 `flex-wrap` 换行，高度 36 → 77 px、CTA 189 → 219 px（反向变松）；追加 `@media(max-width:820px){.toolbar{flex-wrap:nowrap;overflow-x:auto}}` 后回到 36 px / CTA 177 px。
- 「APP 里本地 HTML 以文件卡片能直接预览」：v0.20 起单文件全内嵌、3.67 MB；v0.21 注入 8 层后 **3.77 MB**，孤立文件实测外部引用 0、破图 0、TTS 0。
