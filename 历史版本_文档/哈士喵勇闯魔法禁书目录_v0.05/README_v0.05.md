## 三、为什么这次抠得干净

### 生成侧：从源头让角色「实心」

旧图的病根不是算法，是**角色本身带了一堆封闭空隙**——食蜂卷发之间、爱丽丝金发旁边、神裂黑发下摆、白井双马尾、垣根展开的翅膀下方、去鸣的链条环。这些空隙里全是绿幕，色度抠像要么把绿块留在角色身上，要么把角色抠出洞。

v0.05 把每个角色重画成**单一闭合实心剪影**：

- 幕色换成**高饱和紫红**（与灰白毛、金发、蓝眼、黑发、红发都不接近），一张到底，无渐变纹理、无地面线、无阴影、无文字；角色身上不出现任何紫红／洋红。
- **四肢贴近躯干**：不叉腰、不举手在头侧或腋下留空洞、不把道具举成环形间隙。
- **翅膀与尾巴收拢贴背、发丝画成成片不镂空的块面、道具紧贴身体**。
- 电弧、火焰、未元物质碎片、光环、世界碎片、名牌一律**贴着角色轮廓**，不飘散成独立碎片。
- 边缘清晰、完全不透明，无半透明发丝或粒子穿过轮廓。

### 抠像侧：沿渐变扩散 + 内部补实 + 反解去溢色

| 步骤 | v0.04（旧） | v0.05（新） |
|---|---|---|
| 幕色识别 | 固定色值 + 色相硬判 | 四边每隔 12px 取种子，浮动范围 `floodFill` 沿幕色明暗渐变一路扩散到角色边缘，暗角不漏检 |
| 水印 | 整块涂成采样背景色，留色差 | 逐行取左侧邻近幕色修补，跟随渐变 |
| 内部空隙 | 无处理，绿块留在角色身上 | `inpaint` 补成周围角色色并强制不透明；alpha 内部孔洞一律封掉 |
| 边缘溢色 | 简单压低 G 通道 | 估计逐像素背景场，按 `C_fg=(C_obs-(1-a)·C_bg)/a` 反解半透明边缘 |
| 验收 | 只看缩略图 | 亮青底 halo 检查 + 新旧并排对比 + 逐张残留像素统计 |

**验收结果**：亮青底上 21 个角色边缘干净、无紫红／灰白 halo；不透明区残留幕色判据命中最多 314px（约 0.1%，为角色自身深红／暗紫衣物误检）。内部空隙共补实 47,843px（相对 10 张 2048×1152 图约 0.2%），说明生成侧已基本做到实心，补实只是兜底。

### 代价：动作幅度收小了

为了保证「没有可填充的空隙」，动作从 v0.04 的大开大合收为**收拢式**：一方通行的黑白翼完全收拢贴背、美琴的硬币夹在胸前、爱丽丝双爪合托扑克牌、去鸣的锁链盘成一团贴身。**表情贴合角色和身份层没变**，辨识度改由表情、服装、贴身道具与身体微倾承担。这是「抠图干净」与「动作幅度」之间的取舍，网页舞台页也写明了这一点。
