## v0.05 — 2026-11-07 · 抠图返工：全部重画 + 实心剪影 + 旧图归档

### 用户要求

> 「抠图不是很很干净。之前有背景的直接留存做资产，然后再另外生成可以抠图的使用。注意生成的时候不要在角色身上留绿幕，要让角色没有可以填充的空隙，所有角色都要重新生成。」

### 问题定位

v0.04 的绿幕图里，角色本身带了大量**封闭空隙**：食蜂卷发之间、爱丽丝金发旁边、神裂黑发下摆、白井双马尾、垣根展开的翅膀下方、去鸣的链条环。这些空隙里全是绿幕；色度抠像只吃「与四边连通」的绿幕，封闭区不会被抠掉 → 绿块留在角色身上；若强行抠掉又会留下洞。病根在生成侧，不在算法。

### 落实五条要求

| 要求 | 落地 |
|---|---|
| 抠图不干净 | 换整套抠法（生成侧 + 抠像侧双改） |
| 之前有背景的留存做资产 | 新建 `资产归档/`：`旧版带背景整图/` 12 张、`旧绿幕图_含水印_8张/`、`旧绿幕图_去水印_8张/`、`旧角色层_21张/`、`银时归档_3张/`。**原样留存、不删不覆盖、不参与网页** |
| 另外生成可以抠图的 | 新生成 **10 张紫红幕定妆合页**（9 张双人 + 1 张三人），只服务于抠图 |
| 角色身上不留幕色 / 没有可填充空隙 | 改成「单一闭合实心剪影」 |
| 所有角色重新生成 | **21 个一张旧图都没复用** |

### 生成侧：实心闭合剪影

- 幕色换成**高饱和紫红**（与灰白毛 / 金发 / 蓝眼 / 黑发 / 红发都不接近），一张到底；角色身上不出现紫红／洋红／品红。
- 四肢贴近躯干：不叉腰、不举手在头侧或腋下留空洞、不把道具举成环形间隙。
- 翅膀与尾巴**收拢贴背**、发丝画成成片不镂空的块面、道具紧贴身体。
- 电弧、火焰、未元物质碎片、光环、世界碎片、名牌一律贴着轮廓，不飘散成独立碎片。
- 边缘清晰、完全不透明，无半透明发丝 / 粒子 / 光效穿过轮廓。

### 抠像侧：四步

1. **逐行局部背景修补水印**：每行取左侧 80px 幕色中位数填充右侧水印区，跟随幕色明暗渐变，不留色差块。
2. **多边缘种子 `floodFill`**：从四边每隔 12px 取种子，用浮动范围（loDiff/hiDiff = 13）沿幕色平滑渐变一路扩散到角色边缘；不再用固定色值硬判，暗角不再漏检。
3. **内部空隙补实**：紫红候选与背景区不重合的封闭团（面积 12–120000px）用 `cv2.inpaint` 补成周围角色色并强制 `alpha=255`；alpha 内部孔洞用 floodFill 从边框反查后一律封掉，角色必须是实心块。
4. **alpha 反解去溢色**：用 inpaint 估计逐像素背景场，按 `C_fg = (C_obs − (1−a)·C_bg) / a` 校正半透明边缘（只在 `a>0.28` 且 `8<alpha<250` 时应用）。

输出 21 个带 alpha WebP：网页内嵌版 420px / quality 62（合计 **610 KB**，平均 29.1 KB），高画质版 520px / quality 78 随包。

### 验收

| 检查 | 结果 |
|---|---|
| 亮青底 halo 检查 | 21 个角色叠在高饱和亮青底上，边缘干净，无紫红／灰白 halo |
| 新旧并排对比 | v0.04 上排六人（食蜂 / 爱丽丝 / 神裂 / 去鸣 / 白井 / 垣根）绿块绿边明显；v0.05 下排全部消失 |

| 浏览器 | 21 角色逐一 `setChar` 切换并确认图片加载；9 个页面回归；控制台无报错；`node --check` 通过 |

`美术资产/抠图报告_v0.05.json` 逐张记录内部空隙、alpha 孔洞与边缘溢色校正像素数，可核对。

### 动作取舍（重要）

为保证「没有可填充的空隙」，动作从 v0.04 的大开大合收为**收拢式**：一方通行黑白翼完全收拢贴背、美琴硬币夹在胸前、爱丽丝双爪合托扑克牌、去鸣锁链盘成一团贴身、麦野不叉腰、神裂长刀贴腿侧。`chars_v005.json` 的 21 条 `pose` 全部同步改写，新增 `cutoutNote` 字段并在舞台页明示；构建脚本校验每条 pose 必须含「贴身 / 收拢 / 紧贴 / 收在」等收拢式措辞，避免图文不符。**表情贴合角色与身份层不变**，辨识度改由表情、服装与贴身道具承担。
