# 开源成熟方案借鉴与落地 · v0.37

结论：**不换引擎**，继续单文件 HTML + 每轮增量补素材；本轮沿用已落地约定，未引入第三方代码。

| 借鉴 | 已落地 | 本轮复用 |
|---|---|---|
| WebGAL `background/` 与 `figure/` 分层 | `LAYOUT_RULES.layers` | 贴片层 / 气泡层 / 立绘层互不影响 |
| WebGAL `changeFigureDiff` 只换差分 | `applyExpr()` 只换 src | 角色层零改动 |
| Konva `fitContain()` / PixiJS Layout | `fitBox()` + 自动分层 | 贴片 `object-fit:contain`，场景板 `cover` |
| Ren'Py `zorder` / interact.js `restrictRect` | 声明式边界 + 候选位最小重叠 | 点击气泡避开 HUD/对白/选项、左右钳制 |
| W3C Pointer Events / Phaser 输入 | 小游戏与立绘统一事件流 | 录音面板按钮仍是可点击控件，不依赖拖拽 |
| W3C MediaRecorder / getUserMedia | **本轮新增** `HuskyVoice.record()` | 15 秒上限、错误 resolve、权限被拒给替代路径 |
| WCAG 2.5.7 | 键盘 + 单指针替代路径 | 录音不能用时「📁 导入文件」是完整替代 |
| Bun Standalone HTML / silos-packer | 全内嵌零外部依赖 | 7.57 MB，APP 内文件卡片直接可开 |

## 本轮新增经验
**数据 bug 不要绕判定修**：30 关答案固定 A 看着像「判定太松」，实际是录入时把 `ok:true` 全放索引 0。用关卡 id 做确定性排列直接重排数据，判定函数、键盘映射、语音选择、回顾态全都自动一致；若只在 `choose()` 里加随机或特判，反而会埋下更多不一致。

**录音能力要留降级路径**：`getUserMedia` 在 APP 内嵌 / iOS 可能被拒。接口 resolve `{error}` 而不是抛异常，UI 明确指向「导入本地文件」，保证功能在任何环境都有一条可用路径。
