## 本轮两件事

### ① 「每一关选 A 就过」修掉了
不是判定写错，是**数据层 30 关的 `ok:true` 全写在第一个选项**（实测 30/30）。现在按关卡 id 做**确定性重排**，正确项散到 A–D，同一关每次进入顺序一致、不随刷新漂移；题干、解析、提示一个字没改。

### ② 音频可以导入，也可以自己录
- **📁 导入**：原「🎧 导入语音包」完全保留，`上条当麻_点击.mp3` / `index_happy.wav` 这类文件名自动按「角色 + 情绪」归户

- **接口**：`HuskyVoice.record({maxMs,onTick})` 与 `stopRecord()`，只采集不擅自发声；`register / play / has / list / clear / on / off / attachFiles` 全部保留
- 没片段就静默，**绝不回落 TTS**；朗读默认关仍是全站零播报
