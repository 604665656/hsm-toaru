# 录音与导入说明 · v0.37

## 两种方式，随你挑

**📁 导入本地音频**
设置 →「🎧 导入语音包」，或录音面板里的「📁 导入文件」。支持 mp3 / wav / ogg / m4a / aac / flac，可多选。按文件名自动归户：
- 含角色中文名或 id → 归到该角色
- 再含情绪词 → 同时注册到 `HuskyVoice` 对应情绪槽
- 例：`上条当麻_点击.mp3`、`index_happy.wav`、`一方通行_冷峻.m4a`

**🎤 自己录一句**
1. 设置 → 展开「🎤 自己录一句」
2. 选**角色**（21 个）、**情绪**（8 种）、**用途**
3. 点「开始录」，浏览器会请求麦克风权限
4. 点「停止」结束；忘了点也没关系，**15 秒自动收尾**
5. 自动归户，状态行显示「已录 N 段」
6. 「▶ 试听」听最近一段；「🗑 清空」清掉该角色的自录音频

**用途三选一**
| 用途 | 效果 |
|---|---|
| 点立绘时说（默认） | 注册到 `HuskyVoice` 情绪槽，点对应角色冒气泡时播放 |
| 点立绘 + 角色对白 | 同时注册到 `voicePack`，该角色说话也用这段 |
| 只作角色对白 | 只进 `voicePack`，不参与点击反馈 |

同一角色同一情绪录多段会**自动轮换**，不会每次都同一句。

## 常见问题
- **没声音？** 检查：朗读默认关是正常；录音片段只在你主动点立绘 / 角色说话时才播，不会自动播报
- **点开始没反应？** 看状态行：若提示「当前环境不支持录音」或「麦克风不可用」，说明内嵌预览不给麦克风权限，改用「📁 导入文件」
- **刷新后没了？** 录音与导入都是会话内 Blob URL，刷新需重新来一次
- **能不能录天气音效？** 本轮录音只用于人声语音包；鸟叫 / 雨声 / 虫鸣仍是 Web Audio 合成
- **会不会偷偷联网？** 不会，全程本地 Blob，不上传、不联网取音源

## 无障碍
朗读关闭 = 零 TTS；气泡文字通过 `aria-live` 交给读屏软件。录音面板除拖动手势外，所有操作都是可点击按钮，键盘可达。
