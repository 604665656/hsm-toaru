# 更新日志 · 哈士喵勇闯魔法禁书目录

## 版本号规则

- 从 **v0.01** 开始，每次交付递增 `0.01`：v0.01 → v0.02 → v0.03 …
- 重大重制可跳位（如 v0.10）；同一轮只出一套文件，不覆盖旧版本目录。
- 版本号必须同时出现在：网页标题 / 顶部状态条 / 页脚、README 文件名、CHANGELOG 文件名、资料文档文件名、压缩包文件名。
- 每次交付固定包含：**游戏 HTML + Markdown 文档 + 压缩包**。

## v0.02 — 2026-11-07 · COS 美术最小 MVP

按「先做最小 MVP」的要求，**只做 1 套 COS、1 张三视图展示、1 个全站形象切换**，先把链路跑通。

### 美术

- 新增「COS 衣橱」标签页：左侧展示原作者提供的**「银时」三视图定稿**（正面 / 侧面 / 背面），右侧展示按定稿特征重绘的原创 SVG 全身立绘。
- 新增 `huskyGinHero` / `huskyGinAvatar` 两个内联 SVG symbol：
  - 天然卷白毛（大卷 + 细卷双层路径、阴影 / 白毛 / 高光三遍描边）
  - 圆黑框眼镜、蓝瞳、吐舌、粉腮红
  - 白交领和服 + 蓝花纹、黑羽织与袴、灰腰带
  - 草莓牛奶盒、「洞爷湖」木刀、草莓奶油团子挂饰、蓬松浅灰大尾
- 修正首轮渲染里额前「尖角」与深色尾环：改为柔和白色额纹、浅灰厚涂尾巴。
- 原作者定稿原图随包交付；网页内嵌 1400px 压缩 JPEG（约 153 KB），单文件 HTML 约 424 KB，离线可看。

### 交互

- 「✨ 设为当前形象 / ↩ 换回原设厚涂风」按钮，切换后同步：**顶部品牌头像、开场全身立绘、人格测试结果头像**。
- 状态写入 `localStorage` 的 `cos` 字段；沿用 `hm_v001_state`，v0.01 存档不丢。
- 语音控制新增：`衣橱` / `COS` / `换装` 打开页面，`换形象` / `切换形象` 切换。
- 资料规模栏补「1 套 COS」；「版本 & 操作」页更新本版说明与更新日志。

### 无障碍

- 三视图 `<img>` 带完整中文 alt；COS 切换按钮可键盘聚焦；当前形象用文字而非颜色表示。
- 朗读、键盘、减少动态效果、打印样式等 v0.01 能力全部保留，无控制台报错。

### 资料与校验
