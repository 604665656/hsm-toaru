## 〇、先说两个真 bug

**① 展柜「全屏按不了 / 拖不动 / 点无动画」**

根因是 **ID 撞车**：v0.17 的展柜查看器叫 `#homeStage`，而主页原本就有一个同名的舞台。`document.querySelector('#homeStage')` 永远命中**旧舞台**，于是：

- ⛶ 全屏把 `full` 类加在旧舞台上，展柜画框毫无变化；
- 拖动、滚轮缩放全操作旧舞台，展柜大图纹丝不动；
- 更糟的是 `pickAsset` 把主页原舞台的 class 直接改成了 `asset-stage charm`，主页舞台被破坏。

这版把查看器改名 `…V18` 系列，恢复主页原舞台，旧展柜整体退役重做。

**② 立绘「拉不动 / 缩放会飘」**

普通立绘 `<img class="vn-char breathe-css">` 上的呼吸动画 `breathCSS` 写在 **`transform`** 上。CSS animation 优先级高于 inline style，所以拖拽写的 `el.style.transform` 每帧被呼吸动画覆盖 → 拉不动、放大时像在飘。而且 `.vn-char` 根本没带 `vn-actor` class，交互选择器压根没命中它。

这版把呼吸动画改用独立 `translate` 属性，`transform` 全部留给交互；所有 `.vn-char` 统一挂上 `vn-actor`；`transform-origin` 锁在**脚底**，放大时脚不动、向上长。实测缩放飘移 **0px**。

## 一、这轮做了什么

### 1️⃣ 素材展柜：紧凑 + 自动叠加 + 全屏可用

| 项 | v0.17 | v0.18 |
|---|---|---|
| 缩略图 | 手机 3 列 / 132px 高 | **手机 4 列 / 86px 高**，名称与称号单行省略 |
| 查看器 | 单张图，人物和场景二选一 | **双层叠加**：场景板作底、人物立绘叠在上面，两层始终同时在 |
| 操作层 | 只有一个 | 「✋ 调人物 / ✋ 调场景」切换，两层**分别可拖可缩** |
| 按钮 | 独立一行工具条 | ＋－↺⛶✕ **全浮在画框内右上角** |

| 点击反馈 | 无 | 已解锁弹跳 `th-pop`、锁定项抖动 `th-shake`，选中描边 |

### 2️⃣ 立绘点击 / 拖动都有表演

按角色性格分四种点击反应，带 `navigator.vibrate` 触觉：

| 类型 | 角色举例 | 表现 |
|---|---|---|
| 元气 warm | 本体 / 导览员 / 最后之作 | 弹跳 + ♡ /「啊呜」+ 轻震 `[12]` |
| 冷峻 cool | 一方通行 / 神裂 / 欧提努斯 / 右方之火 | 短抖 +「…」/「哼」+ 双段震 `[22,28,22]` |
| 电波 spark | 御坂美琴 / 食蜂 / 爱丽丝 | 摇摆 + ✦ /「哔哩」+ 连震 `[8,8,8]` |
| 温和 calm | 上条 / 茵蒂克丝 / 馆长 | 弹跳 + ！/「嗯？」+ 轻震 `[10]` |

拖动时冒「🐾 抓起来啦」，松手「轻轻放下～」并回弹；双击单只复位，设置里可全复位。滚轮 / 双指缩放 0.6–2.4×，伪横屏做了旋转坐标换算。

### 3️⃣ 竖屏看得见场景

- 舞台背景按关卡取**横 / 竖版场景板**（竖屏自动用 `_v`）；
- 竖屏角色从 66% 降到 **58%**，气泡更透、遮罩变淡；
- 新增「🖼 看场景」按钮：一点角色与气泡淡到 5%，纯净场景 4.2 秒，再点提前回来。

### 4️⃣ 资料库里终于有图

- 词条详情按 id / 关键词自动挂「🖼 相关素材」：**1 张场景板或设定图 + 2 张人物立绘 = 3 张**，点缩略图开 body 级 lightbox 放大；
- 资料库展柜移到**词条区前面**，默认展开，一进页面就能看到图；
- 新增 2 张设定图专门给「世界 / 设定」类词条：学园都市全景、魔法侧禁书目录书库。

### 5️⃣ 人格测试不再卡死

- 答完第 16 题**立刻**出结果（原来靠 480ms 延时，中途看起来像空白）；
- 题干空白时自动重建，任何异常状态都能自愈；
- 页面顶部常驻「↺ 重新测试 / 卡住点这里」，结果页也有「↺ 再测一次」；
- 实测：16 题答完 → 结果页显示 → 重测回第 1 题 → 手动清空题干后自动恢复。

1. 解压 `哈士喵勇闯魔法禁书目录_v0.18.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.18.html`（Chrome / Edge / Safari，离线可用）。
