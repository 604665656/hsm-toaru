## 二、呼吸帧的生成规格（新增，抄这段就够）

沿用一页纸「只允许两种像素」，再加四条**呼吸差分专用**约束：

1. **以原品红幕合页为唯一基准图做图生图**，不链式、不重画；每次都直接参考同一个原合页，避免多轮漂移。
2. **只改 2% 的起伏**：吸气＝胸腔与肩线整体微抬、尾尖略翘、耳朵极轻上扬；呼气＝整体回落、尾尖略垂。其余毛发、五官、服装、道具、位置、大小、朝向**完全不变**。
3. **背景仍是纯品红／洋红平涂、四角同色**，不因"呼吸"引入地面、投影、光晕、渐变。
4. **轮廓仍完全封闭实心**：不新增镂空、透空指缝／腿缝／腋下、半透明纱、透明玻璃反光；镜片反光保持不透明浅灰白；角色内部不得出现品红像素。严禁人脸、人形身材、人手。

> 为什么用「两帧真图」而不是纯 CSS 缩放：CSS 只能整体缩放，看不出胸腔起伏与尾巴摆动；双帧交替才有"活"的感觉。CSS 只作为**其余 17 个角色**的兜底。

### 命名规范

```
{角色id}_呼吸_{吸|呼}.webp      # 480px 高等比、带 alpha、WebP q74
场景板_{横版|竖版}_{场景名}.webp
```

## 三、网页里怎么"呼吸"

| 角色 | 做法 |
|---|---|
| `base` / `guide` / `touma` / `index`（本轮有帧） | `.vn-actor` 容器内两个 `<img>` 叠放，`breathA` / `breathB` 两条 3.4s 交错动画，交替 opacity + `translateY(-4px) scaleY(1.014)` |
| 其余 17 个角色 | 单张定妆层 + `.breathe-css` 3.4s 微缩放／位移兜底 |
| 系统开启「减少动态效果」 | 全部动画关闭，只显示吸气相，不闪不晃 |
| 角色容器宽度 | 显式给 `width:42% / 24% / 20%` —— span 是空内容容器，shrink-to-fit 会塌成 0 宽（本轮踩过并修掉） |

角色仍 `object-fit:contain`、底部对齐、boundingRect 完整落在舞台内；选项阶段主角色上移到 `bottom:33%`，与控制条留 61px 间隙，副角色淡出到 24% 避免压题干。

## 六、语音包人声（与素材的关系）

「人声」也是素材，但**不能用生成图补**，分三层：

1. **系统语音分角色**（本轮已实现，零素材）：导览员 / 茵蒂克丝 / 上条 / 美琴 / 一方通行各有不同 `pitch` / `rate`，开启「🗣️ 朗读」即用浏览器中文语音包扮演。
2. **自备语音包**（本轮已实现接口）：「⋯ 更多 → 🎧 导入语音包」选本地 mp3/wav，按文件名含角色中文名或 id 自动归户；该角色说话时播放对应音频，未导入的回落分角色 TTS。仅会话内有效，刷新需重新导入。
3. **角色定制音源**（待授权）：真人或定制配音需授权与音频资产，登记为缺口 H 类，本版不生成、不虚构、不含任何原作声优或版权音频。

朗读默认关闭＝全站零 TTS；气泡 `aria-live` 仍把完整句子交给读屏软件；语音包播放时先 `cancel()` TTS，不与读屏抢通道。

### 构图的口径修正（重要）

用户原话：「气泡不是透明的吗，根据实际场景需求进行调整，需要全身就全身，需要半身就下半身在气泡，凸显上半身」。

所以「给上半身更多空间」**不是生成上半身特写图**，而是：把已有的完整角色透明层放大、贴舞台顶部，让下半身延伸到半透明气泡（`.30/.38`）与选项控制条（`.40/.48`）后面。因为气泡是透的，下半身能透出来，视觉上上半身被凸显。按场景自动选 `half`（第 1–3 关）/ `full`（其余），设置里可手动切。

手机竖屏踩过的坑：空 span 容器宽度太窄时 `object-fit:contain` 按宽度缩放会把猫贴到容器底部，只露两只耳朵；已放宽到 88% 并改 `object-position:top center`。
