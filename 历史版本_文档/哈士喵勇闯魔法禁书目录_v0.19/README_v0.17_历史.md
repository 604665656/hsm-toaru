## 〇、先回答「判读还是有问题」

之前题干虽然压成一行，但**点「💡 提示」或答完题仍会冒一个浮在画面中间的「哈士喵的判读」小气泡**（v0.14 留下的 `mode-feedback` 浮空层）。伪横屏旋转 90° 后，这块气泡正好压住角色和选项，竖屏也一样飘着。

这版把**题干、提示、答题反馈全部收进 `#vnCtl` 面板的第一行 `#vnJudge`**——它和四个选项、工具栏是**同一个底框**，竖屏与伪横屏用的是同一条，位置完全一致。浮空的判读气泡彻底退役，对白气泡只负责角色台词。

## 一、这轮做了什么

### 1️⃣ 判读整条贴底（竖屏 / 横屏一致）

| 状态 | 判读条内容 |
|---|---|
| 选项态 | `❓ 选出正确项　四选一 · 答对解锁 · 点「💡 提示」看线索` |
| 点提示 | `💬 哈士喵的判读　💡 提示 · 哈士喵的线索　…　↩ 回到判读` |
| 答题反馈 | `💬 哈士喵的判读　✓ 答对啦 / ✗ 差一点 / 🔎 线索　…　↩ 回到判读` |

实测 `#vnCtl.firstElementChild.id === 'vnJudge'`，选项态与提示态 `#vnDialog` 均 `display:none`，对白态才恢复；手机横屏判读条同样在 `ctl` 内，四选项 4/4 可见。

### 2️⃣ 人格测试那个奇怪贴纸换掉了

结果页的圆脸 SVG 是早期占位图，现在换成**真实抠图的哈士喵本体立绘**（`ART.chars.base`，透明 WebP）。实测结果头像 `tagName=IMG`、`naturalWidth>0`，16 题可一路答完出结果。

### 3️⃣ 素材展柜：主页 + 资料库都有

你说「资料图里面没有场景图或者人物立绘等素材」——补上了，而且主页也放了一份：

- **21 个人物立绘 + 10 张场景板**缩略图，两个 tab 切换；
- 缩略图下方写清「**人物名 + 昵称·花名·职务**」「**场景名 + 出处**」，例如：
  - `上条当麻风` → `幻想杀手 / 不幸体质 · 某高中高一学生 · 右手缠绷带`
  - `御坂美琴风` → `超电磁炮 / 炮姐 · 常盘台中学 · Level 5 第三位`
  - `第七学区 · 上条宿舍阳台` → `旧约 1 · 阳台上掉下来一座图书馆`
- **按进度解锁**：未通关的显示灰度剪影 + 🔒「第 N 关解锁」，通关对应关卡后自动点亮；初始 21 人物锁 19、10 场景锁 9，通关 12 关后人物仅剩「结业馆长」、场景全开。
- **不弹窗**：点缩略图就在展柜内联查看；大图可**拖动 / 滚轮 / 双指 / ＋－ 缩放**、⛶ **铺满全屏**、↺ 复位。
- 人物都是**哈士喵猫身换装**，不是原作角色本人；称号与职务为常识性登记，不虚构剧情。

### 4️⃣ 气泡透明度、音量都能自己拖

设置浮层新增 **5 条滑块**，实时生效并写进存档：

| 滑块 | 范围 | 作用 |
|---|---|---|
| 🫧 气泡透明度 | 0–90% | 同时作用于对白气泡、判读条、选项底框（CSS 变量 `--dlgA`） |
| 🔈 总音量 | 0–100% | `AE.master.gain` |
| 🔊 音效 | 0–100% | `AE.sg.gain` |
| 🎵 音乐 | 0–100% | `AE.mg.gain` |
| 🗣️ 朗读 | 0–100% | `SpeechSynthesisUtterance.volume` |

实测调到 75% 后 `getComputedStyle(--dlgA) = 0.75`、气泡背景 `rgba(…,0.75)`；音效调到 60 后 `AE.sg.gain.value = 0.6`。朗读仍默认关闭，全链路 TTS 计数 0。

### 5️⃣ 立绘能点、能拖、能缩放

| 操作 | 效果 |
|---|---|
| 点一下 | 弹跳 + 冒「！／♡／啊呜／✦」+ 轻音效（0.58s） |
| 按住拖 | 整只猫跟着走；伪横屏做了旋转坐标换算，`ls-flip` 反方向也对齐 |
| 滚轮 / 双指 | 放大缩小 0.6–2.4× |
| 双击 | 这只猫复位 |
| 设置「🐾 重置立绘位置 / 大小」 | 全部复位 |

拖动以 `pointerup` 的最终坐标收口，避免浏览器合并连续 `pointermove` 丢掉半段；实测 `translate(100px,40px) scale(1)` → 滚轮 `scale(1.312)` → 双击 `scale(1)`。点击角色不会顺带推进对白。

### 6️⃣ 场景按原著地标重绘（本轮素材，无需提醒）

你说「随机生成的完全看不出原著的影子」。这轮生成 **8 张地标版场景板**，按原著标志性地点与道具写描述重画：

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.17.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.17.html`（Chrome / Edge / Safari，离线可用）。
2. 主页往下滑是**素材展柜**；资料库页底部也有一份。点缩略图看大图，⛶ 可全屏。
3. 设置里拖「🫧 气泡透明度」和四条音量；剧情里点猫、拖猫、滚轮缩放。
4. 剧情不会就点「💡 提示」，内容直接出现在底部判读条；答对自动给「▶ 下一话」。
5. 朗读默认关，不会自动出声。
