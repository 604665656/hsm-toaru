# 纯色底实心角色层抠图方法

> 可转述给其他项目的一页纸。**抠图干净不是抠得厉害，是画的时候就只允许出现两种像素**：一种是纯色背景，一种是完全实心的角色。

## 一、根因：别在复杂背景里"事后硬抠"

上一版的做法是「先生成带场景的整图 → 再 GrabCut + 椭圆 + 柔边把角色挖出来」，结果必然不干净：

- 白绒毛、白袍、镜片高光、书纸、米色道具，与背景亮度接近，被判成背景挖掉，角色身上出现洞；
- 指缝、腿缝、腋下、剑与身体之间的夹缝本是背景，抠出来成了镂空，边缘还带一圈原场景晕影；
- 半透明玻璃、纱、渐变投影，alpha 里混进背景色，换背景就串色。

**结论：抠图不是后处理问题，是生成约束问题。** 把「可抠」前置成出图规格，旧整图原样归档留作美术资产，另起一套专用源图。

## 二、生成端硬约束（最关键，抄这段就够）

用同一张 Core 图做图生图、固定身份锚点，只改表情/服装/道具。Prompt 里写死：

1. **背景单一均匀的纯品红／洋红平涂（#FF00FF 一类）**，四角同色；无场景、地面、投影、光晕、渐变、纸纹、文字、印章、水印。
   - 不用绿幕：角色主色是灰白绒毛、蓝瞳、粉内耳、黑框眼镜、褐木道具，**品红（R高 / B高 / G明显低）与这套配色色相距离最远**；绿色（G高）容易和暖灰纸纹、赭衣、竹木、暗部橄榄色互相吃阈值。品红在自然插画里也极少主动出现。
2. **角色轮廓完全封闭、实心**：身体与四肢连成一体；不画任何镂空、网格、半透明纱、透空指缝／腿缝／腋下空隙；衣摆封闭；绒毛边缘清晰硬边，不与背景做柔化过渡。
3. **道具紧贴身体或握在爪中**，不与身体形成细长夹缝；披风、飘带、衣袂贴身。
4. **角色内部不得出现任何品红像素**，包括反光、饰品、内耳、白衣、道具。
5. **镜片反光改成「不透明的浅灰白」**，不画透明玻璃 —— 这是最容易被挖出洞的一处。
6. 角色居中约占七成，右下角水印区域后处理里直接抹掉。

> 注意：`binary_fill_holes` 只是**保险**，不是手段。如果生成端留了一堆透空夹缝，填洞会把「剑与身体之间本该有的缝」糊成实心块，视觉上照样穿帮。所以「角色身上不留任何需要填充的空隙」必须在生成时就锁死。

## 三、后处理三道

| 顺序 | 做法 | 解决什么 |
|---|---|---|
| 1 色相键控 | 按色相区间判品红系，不做精确色值匹配 | 模型会画渐变玫红/紫红，精确 `#FF00FF` 会漏 |
| 2 孔洞填实 | 取最大连通域 → `binary_fill_holes` | 兜底：被前景包围的背景岛全归前景 |
| 3 去色溢 | 只修 alpha 内部的品红残点（inpaint） | 模型偶尔仍在衣袖/刀柄上留一小块品红 |

**顺序不能反**：先填洞再 despill。反了会把品红斑当成洞填实，颜色还留在角色身上。

## 四、可直接跑的核心代码

```python
from PIL import Image
import numpy as np, cv2
from scipy import ndimage

def largest(mask):
    n, lab, st, _ = cv2.connectedComponentsWithStats((mask > 0).astype(np.uint8), 8)
    return (lab == (1 + np.argmax(st[1:, cv2.CC_STAT_AREA]))).astype(bool) if n > 1 else mask

def finish(solid, soft):
    """solid: 实心前景 bool；soft: 0..255 连续软边，越大越像角色"""
    inner = cv2.erode(solid.astype(np.uint8), np.ones((3, 3), np.uint8)).astype(bool)
    a = np.where(solid, np.maximum(soft, 190), 0).astype(np.float32)
    a = np.where(inner, 255, a)                      # 内部一律不透明
    return np.clip(cv2.GaussianBlur(a, (0, 0), 0.6), 0, 255).astype(np.uint8)

def cutout(src, dst, size=480, webp_quality=74):
    im = np.array(Image.open(src).convert('RGB'))
    R, G, B = [im[:, :, i].astype(np.float32) for i in range(3)]

    # 1) 品红系判定：R高 / B高 / G明显低，对渐变玫红、紫红都成立
    mag = (R > 145) & (B > 85) & (G < R * 0.60) & (G < B * 0.72) & (G < 125)
    #   连续距离给软边，避免硬阈值产生锯齿
    score = np.minimum.reduce([
        (R - 145) / 60, (B - 85) / 50,
        (R * 0.60 - G) / 40, (B * 0.72 - G) / 40, (125 - G) / 40
    ])
    soft = (255 - np.clip(score * 255, 0, 255)).astype(np.uint8)  # 越大越像角色

    hard = (~mag).astype(np.uint8)
    hard[:, -170:] = 0; hard[-140:, -260:] = 0       # 抹掉右下角水印区
    hard = cv2.morphologyEx(hard, cv2.MORPH_CLOSE, np.ones((5, 5), np.uint8))
    solid = ndimage.binary_fill_holes(largest(hard))  # 2) 孔洞填实

    # 3) 去色溢：只修 alpha 内部的品红像素，背景品红由 alpha 裁掉
    spill = cv2.dilate((mag & solid).astype(np.uint8) * 255, np.ones((3, 3), np.uint8))
    fixed = cv2.cvtColor(
        cv2.inpaint(cv2.cvtColor(im, cv2.COLOR_RGB2BGR), spill, 3, cv2.INPAINT_TELEA),
        cv2.COLOR_BGR2RGB)

    a = finish(solid, soft)
    out = Image.fromarray(np.dstack([fixed, a])).convert('RGBA')
    out.resize((size, size), Image.LANCZOS).save(
        dst, 'WEBP', quality=webp_quality, method=6)

    # 验收：应恒为 0
    holes = int(np.logical_and(ndimage.binary_fill_holes(a > 128), ~(a > 128)).sum())
    return holes
```

**参数口径**：`G < R*0.60`、`G < B*0.72`、`G < 125` 三个条件同时卡，是为了把淡紫装饰（紫荆花之类，G 不够低）保留下来不误伤；软边 `max(soft,190)` 保证主体内部不会被软边吃掉；`GaussianBlur 0.6` 只做半像素抗锯齿，不做羽化。

## 五、工程化与验收

- **分层解耦**：角色层（透明 WebP）与背景板（空场景 JPEG）分开存，组合数 = 背景数 × 角色数，加人物只需一张透明层，不再多存整图。
- **内嵌**：480px WebP（q74 / method 6）转 base64 data URI，单文件离线可用；本项目 11 背景 × 23 角色 = 253 组合，23 层共约 600 KB。
- **量化验收**（比肉眼可靠）：`binary_fill_holes(alpha>128) & ~(alpha>128)` 的像素数必须 **= 0**；再把同一层轮流叠到全部背景板上目检，确认无品红溢边、无原场景残块。
- **分批**：单次生成有张数上限，按批做满即停，每批先接进页面验证再开下一批，不囤图。

## 六、踩过的坑清单

1. 精确色值 `== #FF00FF` 必漏，模型画的是渐变玫红 → 用色相区间 + 连续软边。
2. 透明玻璃反光 / 半透明纱是最大杀手 → 全部改不透明实色。
3. 细长透空夹缝不能靠填洞救 → 生成时让道具紧贴身体。
4. 别对整图做羽化柔边 → 半透明像素会带进背景色，换背景就串。
5. 绿幕不如品红：与灰白/蓝/粉/褐的暖调角色容易混阈值。
6. 先填洞、后 despill，顺序反了颜色残点留在角色里。
7. 旧带场景整图**不要删**、也不要拿来重抠，原样归档做美术资产即可。

## 七、一句话转述给别的项目

> 「不要从成图里抠角色，要**为抠图单独出图**：纯品红平涂底，角色画成完全封闭的实心块、身上一个背景色像素都不许有，镜片反光改不透明；之后只做色相键控、孔洞填实、去色溢三道，alpha 内部孔洞数验收为 0。旧整图留档不参与抠图。」

---

本方法是图像工程口径，与具体题材无关；示例数值来自灰白绒毛 Q 版角色 + 厚涂暖灰场景，换配色时重点重调 `G < R*0.60 / G < B*0.72` 两个比值与 `G < 125` 上限。
