### 实测数据（21 层）

| 指标 | 结果 |
|---|---|
| alpha 内部孔洞 | **全部 0**（总和 0） |
| 大凹陷（25px closing 差集） | 最大 7,205px，全部 < 8,000px 验收线；无「扣没了」的缺块 |
| 不透明区品红残留 | 最大 40px、合计 82px（约 0.002%，为角色自身暖色暗部误检） |
| 21 层体积 | 511 KB，平均 24.4 KB；480px 等比高度 WebP q74 |
| 目检 | 亮青底无品红／灰白 halo；深蓝底边缘干净；魔禁舞台合成无串色 |

工程适配（不改方法口径）：源图是双人／三人合页，**先整图键控 + 抹水印 → 按列投影分格 → 每格独立跑 `largest / fill_holes / despill`**，否则最大连通域只会保住一个角色；输出保持宽高比，不做方形 `resize` 以免 Q 版猫身被压扁；另加两道收尾（透明区 inpaint 填平、半透明边缘按幕色反解），对应踩坑清单第 4 条「别对整图羽化、换背景串色」。

## 三、「人脸变猫」怎么修的

v0.05 的病根其实有两层，只调抠图阈值解决不了：

1. **身份漂移**：食蜂操祈、垣根帝督被模型画成了人形少女／少年——圆滚滚猫头、尖猫耳、圆猫爪全部消失，服装直接长在人身上。
2. **开口缝**：金发卷、帽檐、头巾、翼下、黑发下摆留了连通到画面边缘的幕色缝，floodFill 顺着缝吃进角色内部 → 大块「扣没了」。

v0.06 把「双 Core 合页」作为唯一输入图，提示词把猫身写成**最高优先级铁律**（头占全身一半、尖耳必须露在假发外、圆猫爪不是人手、圆胖猫身、蓬松卷尾），并明确「严禁人类脸／人形身材／人手／人腿；服装道具只是戴在猫身上的小配件」。配合纯品红实心剪影与三道后处理，两个问题一起解决。新旧对比图：`新旧对比_人脸变猫_v0.06.jpg`（上排 v0.05 人脸与残块，下排 v0.06 猫身亮青底）。
