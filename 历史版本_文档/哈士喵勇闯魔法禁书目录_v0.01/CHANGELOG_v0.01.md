# 更新日志 · 哈士喵勇闯魔法禁书目录

## 版本号规则

- 按你的指定，从 **v0.01** 开始。
- 每次交付递增 `0.01`：v0.01 → v0.02 → v0.03 …
- 重大重制可跳位（如 v0.10）；同一轮只出一套文件，不覆盖旧版本目录。
- 版本号必须同时出现在：网页标题 / 顶部状态条 / 页脚、README 文件名、CHANGELOG 文件名、资料文档文件名、压缩包文件名。
- 每次交付固定包含：**游戏 HTML + Markdown 文档 + 压缩包**。

### 玩法

- 30 关四选一，每题详解写成完全剧透；3 档难度；答错可重试，原石狂人难度扣小游戏时间。
- 新增 **👓 剧透显示**总开关：关闭时遮罩「完全剧透」词条正文，方便临时分享。
- 新增 **⏱ 限时小游戏**总开关：关闭后答对直接通关，无障碍用户不被计时挡住。
- 小游戏改为「收集书页碎片」，厚涂渐变背景、哈士喵头像主角、空格哈气推开巡逻球；碰撞或超时也保留本关进度。

### 无障碍与朗读

- 朗读改为**短句队列**，规避部分浏览器网络语音约 15 秒截断；可随时停止。
- 语音控制修正识别结果解析，新增「第 X 关」「搜索 XX」「跨媒体」「剧透」等指令；语音不可用时全部功能仍可点按 / 键盘操作。
- 修正初始化时焦点误落到隐藏面板、资料库列表被 flex 压扁导致文字重叠、通关后自动跳关丢失完成反馈等问题。
- 参考 WCAG 2.2 AA：焦点可见且不被遮挡、24px 以上目标、键盘全可达、动态与音频可停止、不依赖颜色传达状态、`prefers-reduced-motion`、打印样式。

### 资料边界（诚实登记，不编造）

- 日文版：旧约 22 卷 + SS / SS2；新约 23 卷（含新约 22 REVERSE）；创约截至检索快照登记至第 16 卷。
- 本页剧情细目**核实到创约 13**；创约 14—16 只登记卷次存在，不补写人物、转折与结局。
- 繁体中文版具体卷次不写死，以台湾角川官方公告为准。
- 哈士喵 GitHub 与微信表情包：已由原作者授权使用角色，但官方链接尚未提供，页面只预留 `LINKS` 登记位。
- 「白色少女」的归所、创约 13 终章 `4th_HERO` 具体所指：按原书简介与章节标题登记，不作推断。
- 动画、剧场版、游戏与漫画含原创／删节内容，统一单列，不并入小说卷序。

### 构建与校验

- 资料与关卡拆为独立 JSON，构建脚本校验：id 唯一、关联词存在、每关恰有 1 个正确答案、每条词条都有解锁归属、`unlock` 值与关卡一致、测试维度合法、时间线字段完整；校验通过才合成单文件 HTML。
- 用 Chromium 实际渲染验证：首页、资料库、答题通关流程、控制台无报错。
- 最终 HTML 约 202 KB，单文件离线可玩。
