## 一、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.01.zip`。
2. 双击 **`哈士喵勇闯魔法禁书目录_v0.01.html`**，用 Chrome / Edge / Safari 打开即可。
3. **不需要联网、不需要服务器、不安装依赖**；音乐、音效、美术全部在文件内生成或绘制。

首次使用注意：

- 🎵 **背景音乐**默认关闭，点一下「音乐」才启动（浏览器禁止自动播放音频）。
- 🎙️ **语音控制**需要点按授权麦克风；Chrome / Edge / Safari 支持较好，Firefox 桌面版不提供语音识别，此时所有功能仍可点按或键盘操作。
- 🗣️ **自动朗读**默认开启，随时用「⏹ 停止」打断。
- 👓 **剧透显示**默认开启（本版为完全剧透）；临时分享给别人时可一键遮罩。
- ⏱ **限时小游戏**默认开启；关闭后答对即通关，不会被计时或碰撞挡住，适合无障碍使用。

## 三、玩法

- 选难度 → 读「发生了什么」→ 四选一 → 答对解锁剧情详解与词条 → 可选「资料碎片」小游戏 → 下一关。
- **资料库**支持分类筛选与全文搜索；未解锁词条显示「？？？」与解锁关卡，点击相关词可跳转。
- **时间线**里标「约」的日期按季节与前后关系推定，不是官方精确日期。
- **跨媒体**页把原创剧情、改编删节、游戏与日常番外统一「单列」，不并进小说卷序。
- 进度存在浏览器 `localStorage`（键 `hm_v001_state`），不上传任何答题、麦克风或语音数据。点「↺ 重玩」清空。

## 四、键盘与无障碍

| 按键 | 作用 |
|---|---|
| `Tab` / `Shift`+`Tab` | 移动焦点 |
| `Enter` | 激活按钮 |
| `1`–`4` | 选择当前题目选项 |
| `R` / `S` | 朗读本页 / 停止 |
| `M` / `V` | 音乐 / 语音控制 |
| 方向键、`WASD`、`空格` | 小游戏移动、哈气 |

- 朗读按短句切分队列，规避部分浏览器网络语音约 15 秒截断。
- 全部功能可键盘操作；焦点为 3px 实色描边；触控目标不小于 44px。
- 正确／错误同时用「✓／✗」文字与形状提示，不只靠颜色。
- 音乐与音效都可独立停止，不自动播放；支持系统「减少动态效果」与打印阅读。
- 语音指令示例：`地图`、`资料`、`时间线`、`跨媒体`、`测试`、`关于`、`下一关`、`第 5 关`、`搜索 项圈`、`选择一`、`朗读`、`停止`、`重玩`。
