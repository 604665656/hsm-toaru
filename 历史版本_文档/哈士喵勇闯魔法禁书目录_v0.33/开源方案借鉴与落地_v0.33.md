# 开源成熟方案借鉴与落地 · v0.33

调研日期 2026-11-08。结论：**不换引擎**。当前「单文件 HTML + 每轮增量补素材」路线与成熟方案同构，缺的是它们的工程约定，本轮把可落地的部分直接并进代码。

## 视觉小说引擎层

| 方案 | 许可 / 定位 | 可借鉴点 |
|---|---|---|
| **WebGAL / WebGAL Terre** | MPL-2.0，Web 原生，PixiJS 渲染，中文文档 | `background/` 与 `figure/` 分目录分层；`changeBg` / `changeFigure` 各管一层；`-left/-right` 多立绘；`changeFigureDiff` 只换表情不动位置；`setTransform` + `-id` 精确控制单只立绘；Terre 的「拖拽资源池→自动建索引→时间轴预览」 |
| **Ren'Py** | 免费开源，8000+ 作品 | `show ... zorder / behind / onlayer` 声明式层级；`image mary night happy` 用 tag+属性管差分；默认 `master/screens/overlay` 三层 |
| **Monogatari** | MIT，Web/PWA | 离线可安装、存档/回放/自动播放开箱即用；若将来要多端发布可评估 |
| **TyranoScript** | 免费开源，浏览器优先 | 轻量脚本驱动，介于 WebGAL 与 Ren'Py 之间 |

落地：`LAYOUT_RULES.layers` 明确 `{background:'cover', figure:'contain', expr:'contain'}`，`fitBox` 按角色分类型套用，不再逐处改 CSS。

## 渲染与图层

| 方案 | 借鉴点 |
|---|---|
| **PixiJS Layout** | 官方 `objectFit:'contain'/'cover'` 与 `computedPixiLayout` 把 scale/offset 算好，印证「角色 contain、背景 cover」 |
| **Konva.js** | MIT；社区 `fitContain()` 需专门写函数把图等比居中画进 canvas，说明「完整贴图被容器裁切」是通用问题，不是本项目独有 |

落地：`fitBox(cw,ch,iw,ih,mode)` 返回 `{x,y,w,h,s}`；小游戏玩家层 `drawImage` 改用它。

## 输入与拖拽

| 方案 | 借鉴点 |
|---|---|
| **W3C Pointer Events** | 硬件无关统一事件流 `pointerdown/move/up`；`setPointerCapture(pointerId)` 手指滑出画布仍收得到；配 `touch-action:none` 防页面滚动 |
| **Phaser 3 Input** | 把鼠标/触摸/触控笔合成一套 API，`pointer.id` 区分多指；圆形 hit area 更宽容 |
| **interact.js** | `restrictRect({restriction:'parent',endOnly:true})` 边界回弹；snap / inertia |
| **Moveable** | `Draggable / Scalable / Pinchable / Snappable` 能力拆分；transform 层级叠加导致位移不等于设定值——本项目 v0.18 踩过同款坑 |

落地：小游戏 Pointer Events 拖动；`LAYOUT_RULES.actor.snapBack` 声明式回弹；组件 `horizontalClamp` / `mutualExclusive` / `verticalFree` 声明式约束。

## 无障碍（不能省）

WCAG 2.5.7 Dragging Movements（AA）要求拖拽之外有**单指针替代路径**；W3C Pointer Events 规范也明确低层事件要补键盘等价操作。故保留方向键 / WASD、「💨 哈气」按钮、⏭ 跳过，不为简洁删掉。

## 单文件离线打包

| 方案 | 说明 |
|---|---|
| **Bun Standalone HTML** | `bun build --compile --target=browser ./index.html` 把 JS/CSS/图片/字体/WASM 全转 base64 内联，双击离线可用 |
| **silos-packer** | AGPL-3.0 Rust CLI，任意 HTML 项目打成单个自包含 HTML |

当前手搓内嵌已能用（8 MB，APP 内直接预览），后续可换构建脚本稳住体积线。

## 选型建议（若将来立项）

- Web 优先、中文生态 → **WebGAL**（MPL-2.0 + Terre 编辑器）
- 重逻辑 / 长线维护 → **Ren'Py**
- MIT + PWA 离线 → **Monogatari**

当前是增量迭代，迁移成本远大于收益，**继续单文件路线**。
