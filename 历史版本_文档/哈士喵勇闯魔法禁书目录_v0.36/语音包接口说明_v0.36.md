# 语音包接口 · v0.36

对外全局对象：**`window.HuskyVoice`**（版本 `v0.36`）。只播放用户自备 / 自行注册的音频；**没有任何片段时静默返回 `false`，绝不回落 TTS**。朗读默认关 ⇒ 全站零语音播报；气泡文字仍通过 `aria-live` 交给读屏软件。

## 情绪 key（8 个）
`tap`（点击/摸头，兜底） · `happy` · `surprise` · `shy` · `calm` · `cool` · `spark` · `combo`

角色 id 沿用项目内 21 个定稿键：`base` `guide` `index` `touma` `misaka` `accelerator` `kuroko` `kanzaki` `styl` `shokuhou` `othinus` `alice` `kakine` `mugino` `hamazura` `rightfire` `lastorder` `librarian` `tsuchimikado` `shangli` `sakuyo`。

## API

| 方法 | 说明 |
|---|---|
| `register(roleId, mood, src)` | 注册音频；`src` 可为 URL 字符串、`File`、`Blob`、`HTMLAudioElement`，也可传数组。同 key 多条自动轮换 |
| `registerMany({roleId:{mood:src}})` | 批量注册 |
| `play(roleId, mood, opts)` | 播放。查找顺序：精确 key → 同角色 `tap` → `base` 同情绪；都没有则静默。返回 `Audio` 对象或 `false`。`opts.index` 可指定第几条 |
| `has(roleId, mood)` | 是否已有片段 |
| `list()` | 返回全部注册的 `{key:[src...]}` |
| `clear(roleId?, mood?)` | 清空；不传参数全清 |
| `on(ev, fn)` / `off(ev, fn)` | 事件：`register / play / miss / end / error / import` |
| `setVolume(v)` / `getVolume()` | 接口增益 0–1；实际音量 = 总音量 × 朗读音量 × 接口增益 |
| `setEnabled(bool)` / `isEnabled()` | 一键静音接口 |
| `moodOf(name)` / `roleOf(name)` | 从文件名解析情绪 / 角色 id |
| `attachFiles(files)` | 解析 `FileList`：按 `角色_情绪` 归户注册，返回成功条数 |

## 最快上手

```js
// 控制台直接跑：注册一段自备音频，之后点对应角色就会响
HuskyVoice.register('touma', 'happy', myAudioURL);
HuskyVoice.play('touma', 'happy');
HuskyVoice.on('miss', e => console.log('缺片段', e));
HuskyVoice.registerMany({ index: { shy: url1, surprise: url2 } });
```

## 文件名约定（「🎧 导入语音包」）

原有「按角色中文名归户」链路完全保留；文件名里再带情绪词就会**同时注册到接口**：

| 文件名 | 归户 | mood |
|---|---|---|
| `上条当麻_点击.mp3` | touma | tap |
| `index_happy.wav` | index | happy |
| `一方通行_冷峻.m4a` | accelerator | cool |
| `御坂美琴_电波.ogg` | misaka | spark |
| `白井黑子_连点.mp3` | kuroko | combo |

情绪词表：点击 / 轻点 / 摸头 / 戳 / tap / poke / click → `tap`；开心 / 笑 / happy / smile / 欢呼 → `happy`；惊讶 / 吓 / surprise / 吃惊 → `surprise`；害羞 / 脸红 / shy / 蹭 → `shy`；平静 / 温和 / calm / 嗯 → `calm`；冷峻 / 生气 / 不爽 / cool / 哼 → `cool`；电波 / 兴奋 / spark / 噼啪 → `spark`；连击 / 连点 / combo → `combo`。未标注默认 `tap`。

## 与点击台词的联动

`poke18()` → `tap36()` → 抽一条台词（带 mood）→ `HuskyVoice.play(roleId, mood)`。
所以只要按上表导入片段，**点立绘冒出文字气泡的同时就会播对应情绪的人声**；没导入就只有文字与贴片，页面保持安静。

## 边界

- 仅会话内有效（Blob URL），刷新需重新导入
- 不含任何原作声优、版权音频或定制音源；真人 / 定制配音需授权与音频资产
- 播放前会 `speechSynthesis.cancel()`，不与读屏 / 朗读抢通道
- 朗读开关关闭时接口仍可播放自备音频（这是用户主动导入的本地文件，不是自动播报）
