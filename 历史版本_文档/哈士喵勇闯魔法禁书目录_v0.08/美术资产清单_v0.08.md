## 四、代码生成的视觉元素（无图片文件）

| 元素 | 生成方式 |
|---|---|
| 深蓝剧院 UI | CSS 渐变 / 玻璃模糊 / 影院暗角 / 暖金描边 |
| 对白气泡 | CSS 圆角 + 小三角 + 说话人名牌 + JS 打字机 |
| 7 种天气 | Canvas 2D 粒子系统，逐帧 `requestAnimationFrame` |
| 场景音效 | Web Audio 振荡器 + 噪声缓冲实时合成 |
| 关卡立绘排位 | `CAST_MAP` 按 30 关取 1–3 个已有透明层，主 / 副错位 |

**角色不裁剪的 CSS 口径**：`.vn-char` / `.stage-char` / `.char-btn img` / `.roster img` 一律 `object-fit:contain`、`object-position:bottom center`；只有 `.vn-bg` / `.stage-bg` 背景板用 `cover`。主立绘 `height:80% / max-width:42%` 靠右，气泡 `width:52%` 靠左，两者不重叠。
