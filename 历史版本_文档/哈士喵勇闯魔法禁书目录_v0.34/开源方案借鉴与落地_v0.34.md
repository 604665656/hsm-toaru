# 开源成熟方案借鉴与落地 · v0.34

结论：**不换引擎**，继续单文件 HTML + 每轮增量补素材。本轮沿用 v0.34 之前落地的两条工程约定，未引入第三方代码。

| 借鉴 | 已落地 | 本轮复用 |
|---|---|---|
| WebGAL `background/` 与 `figure/` 分层、`changeFigureDiff` 只换差分 | `LAYOUT_RULES.layers` = `{background:'cover',figure:'contain',expr:'contain'}` | 角色层补透明边后仍全部 `contain` |
| Konva `fitContain()` / PixiJS Layout `objectFit` | `fitBox()` + `MutationObserver` 自动套用分层规则 | 全量扫描贴边层时按分层规则区分场景板（不透明）与角色层（透明） |
| Ren'Py `zorder` / interact.js `restrictRect` | `LAYOUT_RULES` 声明式边界 | 容器放大后仍零溢出、回弹规则未触发 |
| W3C Pointer Events / Phaser 输入 | 小游戏鼠标·触屏·触控笔统一事件流 | 拖动逻辑未改，实测 5/5 |
| WCAG 2.5.7 | 键盘 + 💨 按钮单指针替代路径 | 保留 |
| Bun Standalone HTML / silos-packer | 全内嵌零外部依赖 | 145 张唯一图统一重编码，压到 6.9 MB 保证 APP 内文件卡片可直接预览 |

## 本轮新增经验
**「末尾覆盖层」是差分项目的头号陷阱**：字典里改完，文件末尾一句 `ART.expr.touma='…'` 就能把旧层写回来。
→ 规则升级：任何批量替换贴图，必须**全量扫描所有 `data:image` 出现处**，而不是只改字典声明处；改完复扫验证剩余贴边层 = 0。

## 选型（若将来立项）
Web 优先 → WebGAL（MPL-2.0 + Terre）；重逻辑 → Ren'Py；MIT + PWA → Monogatari。当前增量迭代迁移成本远大于收益。
