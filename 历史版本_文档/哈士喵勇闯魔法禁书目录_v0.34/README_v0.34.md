## 你说的「个别关卡没修复」是两类，都不是羽化/毛边

**① 角色层**：第 1、4、5、6、10 关早已换成四周 67–94px 安全留白层，但**第 3、7、8、11、12 关还在用只有 10px 贴边的旧层**——所以大部分关看着完整，个别关看着像被切。更隐蔽的是文件末尾 `v0.31 覆盖层` 用 `ART.expr.xxx='…'` 逐条赋值，把 23 个层又写回了旧版，前面的字典替换根本盖不住它。

这轮做**全量扫描**：所有透明角色贴图，凡四周留白 <30px 的，只在四周补透明边到 70px；**可见像素一个不动**，不羽化、不加毛边、不描边。含末尾覆盖层漏网层共补 37+22 个唯一贴图，复扫**剩余贴边层 = 0**。

**② 场景板**：竖屏媒体查询里 `.vn-bg{object-fit:contain!important;object-position:50% 0%}` 把横版场景板挤成舞台中间一块矩形贴片，四周露出全屏背景的放大版，看着就像背景被裁了一块。现在竖屏统一 `cover` 铺满、横竖都全屏；「🖼 看全场景」纯净模式仍 `contain` 完整显示。
