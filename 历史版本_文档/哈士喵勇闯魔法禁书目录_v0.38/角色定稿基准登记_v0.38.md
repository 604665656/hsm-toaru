# 角色定稿唯一基准 · v0.38

**唯一基准 = v0.06 的 21 张角色层**，原样留档在 `美术资产/定稿层_21张_原始留档/`。

## 本轮验证了一条重要经验
用户提出「之前不是一次性生成多个角色吗，画布大一点」。照做后：
- **纯文生图 2×2 大合页**（1536²）→ 平涂描边细长站立版、爱丽丝卷发形变、上里与上条撞脸 → 否决
- **定稿 4 层确定性拼成 1536² 大合页 → 图生图** → 四只都保住厚涂画风、服装道具、圆润体型，只微调表情 → 采用

结论：**一次性画多个角色是可行的，但必须把定稿层拼成大画布作为图生图基准**；纯文字锚点不足以锁住 4 只猫的一致性。这正是 v0.24 之后把定稿定为唯一基准的原因。

## 差分硬规则
1. 只在定稿基准上图生图，禁止整批重画
2. 单一纯品红幕、实心闭合、无夹缝、身上无品红像素
3. 色相键控 → 连通域筛选 → `binary_fill_holes` → 去色溢（严格阈值）
4. 孔洞 `>8` 与 `>128` 都 = 0、无水印
5. **禁止对完整贴图做羽化 / 毛边 / 描边修补**；边缘问题先查画布比例与 `object-fit`
6. 任何批量替换贴图必须全量扫描所有出现处，末尾覆盖层会写回旧值
7. 已有差分能覆盖登场角色时，优先扩索引而非重新生成
8. 画布相对角色留白 ≥15%；抠图层统一 pad ≥80px 安全边
9. 改显示源前先查末尾覆盖层；显示类修复跑多视口矩阵
10. 新增差分按关卡查表叠加，并在 `vnRender` 之后重新叠加（对白刷新会重置 img src）
11. 多角色合版用确定性拼版，AI 只用于「保基准 + 小改动」
