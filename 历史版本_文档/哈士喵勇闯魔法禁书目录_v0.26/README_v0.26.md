**双击 `哈士喵勇闯魔法禁书目录_v0.26.html` 即玩**，全内嵌、零外部依赖，APP 内以文件卡片打开即可，无需下载其他文件、无需解压。

## 本轮三个修复

**① 第 4 关后不能下一关**
根因：默认「限时小游戏」是开的，答对后会弹 `confirm("进入资料碎片小游戏？")`。点「确定」就进小游戏，`finishQuest` 一直不调用，通关进度不加 4，自然永远没有下一话。
修复：**去掉确认框**，答对直接完成本关并浮出「✓ 本关完成 / ▶ 下一话 · 第 5 关」卡片；资料碎片小游戏改成卡片上的**可选按钮**，不阻塞剧情。实测限时开、对话框自动确定的情况下也能进第 5 关。

**② 回弹机制**
根因：`v19ActorLegal` 把「与 HUD / 控制条 / 通关卡重叠 40%」都判为非法，而半身构图本来就允许下半身没入气泡；不合法时又直接跳回 `lx/ly`（进关时由算法往右上挪 14 步算出的旧坐标），一松手猫就飞到奇怪位置。
修复：只拦「几乎整只跑出舞台（可见 <34%）」与「几乎整只钻进对白气泡（>55%）」；不合法时**从松手位置按比例就近回缩**到最近的合法点，不再跳回旧坐标；`ensureVisible19` 不再强挪默认构图；停用重复的一套 `pointerup` 写入。实测大幅拖出画面后松手，可见面积 93%，停在合理位置。

**③ 第 4 关茵蒂克丝被切一点**
根因：全局 `.bf{object-position:top center}` 让第 4 关起的表情层全部贴顶，副角色脚部被气泡压住；第 1–3 关用的是呼吸双帧，不受影响。
修复：`.vn-actor.sub.expr-static .bf` 改回 `bottom center`。实测副角色 `object-position: 50% 100%`，主角色保持贴顶半身构图。

## 操作
- 剧情页「🖼 看全场景」＝纯净场景开关；「⛶ 横屏」＝ CSS 伪横屏，需手动把手机横过来
- 通关卡片：▶ 下一话 / 🗺 回地图 / ↺ 重看本话 / 🎮 资料碎片（可选）/ ✕ 留在本话
- 立绘可点、可拖、可滚轮缩放；双击或「🐾 归位」复位；弹回就近收口
- 设置浮层：气泡透明度、音量、震动反馈、构图切换；✕ / Esc / 点遮罩都能关
