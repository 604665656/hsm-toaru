## 复现 Toy 上架包

平台硬规则：**入口 `index.html` 解压后 ≤ 1MB**、资源必须相对路径（Toy 跑在 `/toy/<slug>/` 下）。原始单文件 8.36MB 不能直接传，构建脚本只写 `toy/`，**不动任何源文件与历史版本**：

```bash
python build_toy.py
python gen_cover_icon.py
```

构建做的事：

1. `<script>` 里 226 处 `data:image/webp;base64` 解码成真实图片、按内容 SHA1 去重 → **169 个文件**，引用改为 `./assets/<hash>.webp`；
2. 唯一的 `<script>`（8,084,607 字符）→ `./app1.js`；
3. **`<style>` 保持内联**：它含 44 处 `url(#runes)` / `url(#glow)` 等 SVG fragment 引用，外置成 CSS 后这些引用会相对 CSS 文件解析而失效、滤镜与渐变全丢；内联 104KB 远低于 1MB 上限，保留最稳妥。这一点和《杯雪》那套（外置全部 CSS）不同；
4. 入口剩 134,812 B，外链 0、根绝对路径 0、残留 base64 0（15 条资料出处链接仍在 `app1.js` 里，为文本引用而非资源依赖）。

产物 171 个文件 / 4,784,723 B，上架 ZIP 4,402,597 B。发布前四道校验：`node --check app1.js`、资源引用完整性（169 引用 0 缺失 0 冗余）、`toy_doctor.py` 预检（`ok=true`，0 findings）、本地起 `/toy/hsm-toaru/` 子路径服务器用真实浏览器确认大厅 → 关卡地图（背景板 + 立绘 + 素材展柜 + 章节解锁）全部渲染。
