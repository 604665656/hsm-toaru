# CHANGELOG v0.38

## ① 画布诊断（回应用户「生成的还是有裁剪」）
| 项 | 上一条 4:5 单角色 | v0.38 大合页 |
|---|---|---|
| 输出尺寸 | 1408×1664 | **1536×1536**（4 格各 768²） |
| 生成方式 | 图生图，单角色 | 图生图，2×2 一次 4 只 |
| 前景左右留白 | 27–40px（≈2%） | **205–272px（≈27–35%）** |
| 触边像素 | 0（严格意义没裁） | 0 |
| 抠图后安全边 | — | **统一 85px** |

结论：不是羽化 / 毛边 / CSS / 载入盒，是**画布相对角色太小**导致视觉裁切感。按用户判断扩大画布，未对完整贴图做任何边缘修补。

## ② 两条生成路线，一条否决一条采用
- **纯文生图 4 角色合页**（seed 4）：漂成平涂描边、细长站立全身、爱丽丝卷发形变、上里与上条撞脸 → 否决留档，不补同款
- **图生图 4 角色合页**（seed 4）：输入是把 4 张带 80px 安全边的定稿层确定性拼成 1536² 大合页；prompt 只要求极轻微改表情、完整保留服装道具／厚涂画风／圆润体型／四周留白 → 采用

这条也印证了 v0.24 起「21 张定稿唯一基准」的必要性：一次性画多个角色必须挂定稿基准，否则必漂移。
