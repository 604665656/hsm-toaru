# 语音包接口 · v0.38

对外全局对象 **`window.HuskyVoice`**。只播放用户自备 / 自录 / 自行注册的音频；**没有片段时静默返回 `false`，绝不回落 TTS**。朗读默认关 ⇒ 全站零语音播报；气泡文字仍通过 `aria-live` 交给读屏软件。

## 情绪 key（8 个）
`tap`（点击/兜底） · `happy` · `surprise` · `shy` · `calm` · `cool` · `spark` · `combo`

角色 id 沿用 21 个定稿键：`base guide index touma misaka accelerator kuroko kanzaki styl shokuhou othinus alice kakine mugino hamazura rightfire lastorder librarian tsuchimikado shangli sakuyo`。

## API

| 方法 | 说明 |
|---|---|
| `register(roleId, mood, src)` | 注册音频；`src` 可为 URL 字符串、`File`、`Blob`、`HTMLAudioElement` 或数组，同 key 多条自动轮换 |
| `registerMany({roleId:{mood:src}})` | 批量注册 |
| `play(roleId, mood, opts)` | 精确 key → 同角色 `tap` → `base` 同情绪；都没有则静默。返回 `Audio` 或 `false` |
| `has / list / clear` | 查询 / 列出 / 清空（`clear(roleId)` 清该角色全部情绪） |
| `on / off` | 事件 `register / play / miss / end / error / import` |
| `setVolume / getVolume / setEnabled / isEnabled` | 增益 0–1、开关；实际音量 = 总音量 × 朗读音量 × 接口增益 |
| `moodOf(name) / roleOf(name)` | 从文件名解析情绪 / 角色 id |
| `attachFiles(files)` | 解析 `FileList` 按「角色_情绪」归户注册 |
| **`record(opts)`** | **本轮新增**：`opts.maxMs`（默认 15000）、`opts.onTick(sec)`；返回 `Promise<{blob,url,size}|{error}>`，只采集不发声 |
| **`stopRecord()`** | **本轮新增**：主动结束当前录音并 resolve |

`record()` 内部用 `getUserMedia({audio:true})` + `MediaRecorder`，自动选 `audio/webm;codecs=opus` 或 `audio/mp4`；不支持或权限被拒时 resolve `{error}`，不抛异常。

## 最快上手

```js
// 导入 / 注册
HuskyVoice.register('touma','happy',myAudioURL);
HuskyVoice.play('touma','happy');
HuskyVoice.on('miss', e => console.log('缺片段', e));

// 自己录一句（3 秒后停止）
const h = HuskyVoice.record({maxMs:15000, onTick:s => console.log(s)});
setTimeout(() => HuskyVoice.stopRecord(), 3000);
const r = await h;
if (!r.error) HuskyVoice.register('index','shy',r.blob);
```

## 设置面板「🎤 自己录一句」
选角色 / 情绪 / 用途 → 开始录 → 停止（或 15 秒自动收尾）→ 自动归户 → ▶ 试听 → 🗑 清空。
用途 `tap` = 点立绘时说；`both` = 点立绘 + 角色对白；`line` = 只作角色对白（注册到 `voicePack`）。

## 文件名约定
| 文件名 | 归户 | mood |
|---|---|---|
| `上条当麻_点击.mp3` | touma | tap |
| `index_happy.wav` | index | happy |
| `一方通行_冷峻.m4a` | accelerator | cool |
| `白井黑子_连点.mp3` | kuroko | combo |

情绪词：点击/摸头/戳/tap/poke/click → `tap`；开心/笑/happy/smile → `happy`；惊讶/吓/surprise → `surprise`；害羞/脸红/shy/蹭 → `shy`；平静/温和/calm/嗯 → `calm`；冷峻/生气/哼/cool → `cool`；电波/兴奋/spark/噼啪 → `spark`；连击/连点/combo → `combo`。未标注默认 `tap`。

## 边界
- 仅会话内有效（Blob URL），刷新需重新导入或重录
- APP 内嵌预览 / iOS 若不允许麦克风，请用「📁 导入文件」，面板会明确提示
- 不含任何原作声优、版权音频或定制音源
- 播放前 `speechSynthesis.cancel()`，不与读屏 / 朗读抢通道
- 朗读开关关闭时接口仍可播放用户自备音频（主动导入，不是自动播报）
