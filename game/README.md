# 哈士喵勇闯魔法禁书目录

《とある魔术の禁书目录》剧情导览同人 AVG，单文件 HTML，双击 `index.html` 即可在浏览器运行，无需构建、无外部依赖。

## 玩法
- 33 关，每关：阅读对白 → 回答问题 → 查看解锁词条
- 点击画面 / 「下一句」推进对白，「⏭」跳到选项，「⛶」切横屏
- 设置里可切换氛围标签（仅文字标签，不播放音频）；全程不请求麦克风

## 部署
- GitHub：把本目录推到仓库，开启 Pages（main / 根目录）即可访问
- Itch.io：把 `index.html` 压成 zip 上传，勾选 *This file will be played in a browser*

## 已知问题
- 第 33 关御坂妹妹暂用御坂美琴立绘（库中无御坂妹妹独立立绘）
- 场景板明暗跨度较大（亮度约 47～194（未统一）），尚未做统一调色
- 资料页部分角色仅有立绘、无情绪差分
