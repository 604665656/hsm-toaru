## 一、登记原则（沿用已验证的一页纸方法）

1. **角色层仍按《纯色底实心角色层抠图方法》出图**：纯品红／洋红平涂、四角同色；角色轮廓完全封闭实心、不留镂空／半透明纱／透空指缝腿缝腋下；角色内部不得出现品红像素；镜片反光改不透明浅灰白；道具贴身。
2. **展开翼、火焰、金币雨、红雪、冲击波等飘散物一律画进「场景板」或独立特效层**，角色层保持闭合剪影——这是 v0.05 开口缝缺块的根因，不能重犯。
3. **表情差分与姿态差分分开出图**：同 Core 图生图，固定身份锚点（原作者眼镜猫三视图 + 标准 Q 版猫身），只改表情／动作，避免 v0.05 的人脸漂移。
4. **不虚构剧情**：缺口描述只写「表演层缺什么」，不补写未核实的卷章细节；创约 14—16 卷、繁中版卷次沿用 v0.01 边界。
5. **旧资产不删不重抠**：v0.03 带背景整图、v0.04 绿幕、v0.05 紫红幕与抠坏层全部留在 `资产归档/`，不参与新批次。
6. 每次补齐仍按版本号规矩交付：HTML + Markdown 文档 + zip，版本号递增 `0.01`。

## 二、当前「动画表演」是怎么凑出来的

| 层 | 现在用什么 | 明显不足 |
|---|---|---|
| 角色 | 21 张收拢式定妆层（v0.06），每关按 `CAST_MAP` 取 1–3 张错位摆放 | 一套姿势走完全部 30 关；没有跑、举手、回头、倒地、展翼 |
| 表情 | 每张定妆层自带一个固定表情 | 没有同一角色的惊／哭／怒／笑差分，剧情转折时表情不变 |
| 场景 | 1 张共用魔禁画风舞台（v0.04） | 30 关同一背景；没有室内／河边／北冰洋／巴盖吉城等环境区分 |
| 特效 | 7 种 Canvas 天气粒子（v0.08） | 只有氛围，没有电弧、魔法阵、冲击波、金币雨等剧情特效 |
| 演出 | 对白打字机 + 名牌 + 选项 2 列横条 + 气泡透明度 | 没有转场、镜头推拉、待机眨眼／呼吸、词条解锁演出 |
| 声音 | Web Audio 合成天气音 + 少量交互音效 | 没有脚步／衣物／道具／远近环境分层 |

**结论**：目前是「静态立绘 + 氛围粒子 + 文字演出」，离「动画表演」还差 A–H 八类素材。

## 八、验收口径（补图时照旧）

- `binary_fill_holes(alpha>128) & ~(alpha>128)` 像素数 **= 0**；
- 不透明区品红残留 ≤ 40px；大凹陷 < 8,000px；
- 同一层轮流叠到全部场景板上目检：无品红溢边、无原场景残块；
- 角色层四边 alpha 全 0（不贴边被切）；
- 所有角色图 `object-fit: contain`，boundingRect 完整落在舞台内，气泡不压 HUD／角色；
- 每批先接进页面验证再开下一批，不囤图。
