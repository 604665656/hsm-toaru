## 版本号规则

- 从 **v0.01** 开始每次交付递增 `0.01`：v0.01 → … → v0.10 → v0.11 → **v0.12**。
- 版本号同时出现在：网页标题 / 状态板 / 页脚、README、CHANGELOG、资料文档、计划文档、登记文档、压缩包名。
- 每次交付固定：**游戏 HTML + Markdown 文档 + 压缩包**。
- **v0.11 起**：每轮只要发现缺素材，就顺手生成一批并接进页面，不再只登记。

## v0.12 — 2026-11-07 · 全屏横竖背景 / 半身构图 / 更透气泡 / 独立设置 / 补素材

### 用户反馈

> 「背景要能全屏不论横屏竖屏，尽可能给人物上半身多一点空间，对话框气泡的透明度再高一点，气泡能小尽量小一点，设置按钮能隐藏的尽量隐藏或者尽可能简洁但是能展开，或者有单独的设置界面（要记得设置能关闭能退出的按钮最好放显眼的位置，如果太长要能拖动），那只首页的那个头像框的猫要么替换素材要么去了吧，好丑不是图生图的，记得本轮也要补充素材哦」
>
> 中途纠正：**「不用上半身特写」** —— 「就是在有部分在对话气泡里面，但是气泡不是透明的吗，根据实际场景需求进行调整，需要全身就全身，需要半身就下半身在气泡，凸显上半身」。

### ① 全屏背景：默认开启，横竖 / 伪横屏都铺满

- `body.bg-full` 改为**页面加载即开启**，`#fullBg` `position:fixed; inset:0; object-fit:cover`；
- `SCENE_MAP={1:'balcony',2:'seminary',3:'river'}`，`sceneSrc(portrait)` 按当前关卡 + 方向取 6 张场景板之一；
- **伪横屏时 `#fullBg` 也 `rotate(90deg)`**（`body.ls-flip` 用 `-90deg`），横过手机后背景仍铺满视口，不再出现「竖图被裁成一条」；
- `sceneApply()` 在 `renderQuest` / `enterLandscape` / `exitLandscape` 之后重新套用；`resize` / `orientationchange` 跟随；
- 主行「🖼 背景：开」可一键关，关掉后舞台内恢复 16:9 背景。

### ② 构图：不是特写，是按场景全身 / 半身

- `state.frame`（`auto` / `full` / `half`）+ `QUEST_FRAME={1:'half',2:'half',3:'half'}`；
- 半身＝角色整体放大、**贴容器顶部**（`object-position:top center`），下半身延伸到半透明气泡与控制条后面，凸显上半身；全身＝完整贴底；
- **修掉手机竖屏只露两只耳朵的 bug**：根因是 `.vn-actor` 空 span 宽度太窄，`object-fit:contain` 被宽度限制把猫压到容器底部；手机把容器放宽到 88% 并改贴顶，实测头顶在舞台 8%、上半身完整；
- 设置里「角色构图」下拉可手动切，语音说「半身 / 全身」也可切；
- 副角色提亮到 90%（选项阶段 60%）并下移到 `top:17%`，避开题干胶囊；
- 全身构图选项阶段抬到 `bottom:29%`，实测不压控制条。

### ③ 气泡更透更小

| 项 | v0.11 | v0.12 |
|---|---|---|
| 玻璃底 | `rgba(.58/.66)` | **`rgba(.30/.38)`** |
| 模糊 | `blur(11px)` | `blur(5px)` |
| 对白气泡宽 | 52% | **44%** |
| 题干胶囊宽 | 58% | **46%** |
| padding | 13px | 9px |
| 控制条 | `.60/.70` | **`.40/.48`** |
| 选项按钮 | `.74` | **`.55`** |

文字改三层投影保可读；题干文案缩成「选出正确项」，手机一行放得下；选项阶段隐藏「竖屏建议点横屏」提示。

### ④ 独立设置浮层

- 主行只留 **⚙ 设置 / 🌤 场景 / ⛶ 横屏 / 🖼 背景**；全部次要控件（13 个）移进 `#settingsPanel`；
- **显眼关闭**：右上角 44×44 大红 ✕ + 底部通栏「✕ 关闭设置」+ `Esc` + 点遮罩，四种都能关；
- **太长能拖动**：`#settingsBody` 可滚动（手机实测 `825 > 574`），`#settingsHead` 用 pointer events 支持鼠标 / 触摸拖动（实测位移 −140 / +42 px）；
- 分组：声音 / 画面与构图 / 玩法与无障碍；「⋯ 展开更多页面」入口也收进来；
- 所有原按钮 **id 与事件绑定保持不变**，只是换了位置，无功能回归。

### ⑤ 首页头像框去掉

- 移除 masthead 里的 `<svg use="#huskyAvatar">` 猫头（不是图生图的，用户嫌丑），改纯文字标题 + 4 格状态板；
- 本轮生成的 1:1 头像特写按「不用上半身特写」**留档不采用、不进网页**，存于 `美术资产/头像候选_未采用/`。
