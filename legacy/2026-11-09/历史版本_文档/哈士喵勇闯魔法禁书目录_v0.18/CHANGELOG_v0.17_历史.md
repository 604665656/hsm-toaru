## 版本号规则

- 从 **v0.01** 开始每次交付递增 `0.01`：v0.01 → … → v0.15 → v0.16 → **v0.17**。
- 版本号同时出现在：网页标题 / 状态板 / 页脚、README、CHANGELOG、考据、计划、登记、资产清单、压缩包名。
- 每次交付固定：**游戏 HTML + Markdown 文档 + 压缩包**。
- **v0.14 起的硬规则继续生效**：每轮固定生成素材，不需要用户提醒 —— 找下一批缺口 → 生成 → 验收 → 接进网页 → 更新六份文档。

### ① 判读「整条贴着下面」

根因：v0.15 只把题干压成一行，但 v0.14 留下的 `vnFeedback` 包装仍会弹出浮空的 `mode-feedback` 小气泡（名牌「💬 哈士喵的判读」+ 提示/反馈文字），伪横屏旋转后正好压住角色和选项。

修复：

- 题干 / 提示 / 答题反馈统一写进 `#vnCtl` **首行 `#vnJudge`**，与四个选项、工具栏同一底框；
- `.vn-dialog.mode-choice,.mode-feedback{display:none!important}`，浮空判读气泡退役，对白气泡只负责 `vnLines`；
- 重写 `window.vnFeedback`（不再调用旧包装），提供「↩ 回到判读」；`vnRender` 包装只清 `mode-feedback`，不再误删 `mode-choice`；
- 竖屏与伪横屏共用同一 `#vnCtl`，位置天然一致。

实测 `ctl.firstElementChild.id === 'vnJudge'`，选项态 / 提示态 `#vnDialog` 均 `display:none`，对白态恢复 `block`；手机横屏判读条仍在 `ctl` 内，四选项 4/4。

### ② 人格测试贴纸

`showQuizResult` 的 `<svg class="av"><use href="#huskyAvatar"/></svg>` → `<img class="av" src="ART.chars.base">`（真实抠图立绘，CSS `object-fit:contain`）。实测 `tagName=IMG`、`naturalWidth>0`，16 题可答完。

### ③ 素材展柜（主页 + 资料库）

- 通用组件 `buildAssetCase(prefix)` / `renderAssetCase(prefix)`，两处实例：`home`、`codex`；
- **21 个人物立绘 + 10 张场景板**两个 tab；缩略图带「人物名 + 昵称·花名·职务」「场景名 + 出处」；
- **按进度解锁**：`at===0 || state.cleared.includes(at)`，未解锁灰度剪影 + 🔒「第 N 关解锁」；初始人物锁 19 / 场景锁 9，通关 12 关后 1 / 0；
- **内联查看不弹窗**：点缩略图换大图，大图可拖动 / 滚轮 / 双指 / ＋－ 缩放、⛶ CSS 全屏、↺ 复位；
- 切关 / 通关经 `renderMap` 包装刷新解锁态。

### ④ 气泡透明度 + 四类音量可拖

- 设置新增 5 条滑块：🫧 气泡透明度（0–90%，CSS 变量 `--dlgA` / `--dlgA2`）、🔈 总音量、🔊 音效、🎵 音乐、🗣️ 朗读；
- `applyAlpha()` 同时作用于对白气泡、判读条、选项底框；`applyVol()` 写 `AE.master/sg/mg.gain`，朗读写 `SpeechSynthesisUtterance.volume`；音频上下文首次手势后补套；
- 全部写进 `state` 存档。实测透明度 0.30→0.75、音效 60→`AE.sg.gain=0.6`。

### ⑤ 立绘交互

- 事件委托：点击 → `poke` 弹跳（CSS 独立 `translate` 属性，不冲突拖拽 transform）+ 冒符号 + 轻音效；
- 按住拖 → 位移，伪横屏按 `ls-mode` / `ls-flip` 做旋转逆换算；**以 `pointerup` 最终坐标收口**，避免浏览器合并 `pointermove` 丢半段；
- 滚轮 / 双指 → 缩放 0.6–2.4×；双击 → 单只复位；设置 → 全部复位；
- capture 阶段拦截角色点击，不误推进对白。

实测 `translate(100px,40px)` → 滚轮 `scale(1.312)` → 双击 `scale(1)`。
