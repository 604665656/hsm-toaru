## 一、这轮做了什么

### 1️⃣ 主页：首屏只剩「开始」

- `#home` 重构为 `home-cta` + 一个可折叠 `<details>`：
  - 首屏只有一个 **82px 高的金色大按钮「▶ 开始冒险」**、一行副标题、一行进度；
  - 玩法长文、三步卡、难度下拉、资料规模、角色预览全部收进「玩法说明 · 难度 · 资料规模」，**默认收起**；
  - 所有原 id（`startBtn` / `diff` / `homeScale` / `continueInfo` / `homeStage` / `homeChar`）保留，旧逻辑不回归；
- 手机再把 masthead 状态板收掉（标题压成一行、36px 高），大按钮 top 从 248 提到 **189px**，首屏上半部就能看见；按钮小字随存档变成「继续 · 已通 N / 30 关」。

### 2️⃣ 「哈士喵的判读」气泡缩小

反馈原来复用了底部选项大条的 `mode-choice`（60% 宽 / 37% 高），长文一撑就占半屏。现在改成独立 `mode-feedback`：

- **38% 宽 / 32% 高**（手机 66% / 30%，横屏 34% / 36%），实测实际占屏 38% × 16%；
- 去掉 `backdrop-filter`（避免把后面的角色糊成一片），用 `.54/.62` 实底 + 文字投影保可读；
- 「↩ 回到对白」从底部控制条**收进气泡内**，控制条里不再多一根竖条；
- `vnRender` 包装会在回到对白时清掉反馈样式，不会残留小气泡。

### 3️⃣ 上条当麻 cos 不再是幽灵

**根因有两个，都是动画／透明度，不是素材画坏了：**

| 根因 | 原状态 | 修复 |
|---|---|---|
| 双帧呼吸用 `ease-in-out` 交叉淡化 | 25% / 75% 时刻 A、B 两帧各 `opacity .5`，两张略错位的图叠成**重影＋半透明** | 改成**硬切**：0–49.9% 只显示 A，50–100% 只显示 B，任一时刻只有一帧可见；采样 14 次恒定 `[1,0]` |
| 选项阶段副角色被压暗 | `.24`（sub）/ `.20`（sub2），上条恰好是副角色 | 提到 `.86` / `.76`，半身构图 `.90`；反馈态全部 `1` |

顺手也给表情差分静态层加了 `.expr-static`，关掉双帧动画只显示一帧，不会出现第三重重影。

### 4️⃣ 每轮固定生成素材（本轮实际产出）

|---|---|---|
| 上条苦笑 / 茵蒂克丝委屈 品红幕合页 | 1 | 2 个透明表情层 |

- **5 张生成原图 → 10 个可用透明层**，全部按一页纸规格：纯品红平涂、闭合实心剪影、镜片反光不透明、角色身上无品红像素；生成端只改表情与极轻微姿态，身份层不变，逐张目检**全是猫、无人脸漂移**；

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.14.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.14.html`（Chrome / Edge / Safari，离线可用）。

3. 进「剧情关卡」玩第 1–6 关；其余显示「敬请期待」。
4. 点「⛶ 横屏」→ 把手机横过来，右侧中部两个小圆钮分别是 ↩ 退出、⟳ 换方向，不压任何内容。
5. 朗读默认关，不会自动出声。
