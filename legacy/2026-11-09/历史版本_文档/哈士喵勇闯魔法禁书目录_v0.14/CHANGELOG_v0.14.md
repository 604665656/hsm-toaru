# 更新日志 · 哈士喵勇闯魔法禁书目录

## 版本号规则

- 从 **v0.01** 开始每次交付递增 `0.01`：v0.01 → … → v0.12 → v0.13 → **v0.14**。
- 版本号同时出现在：网页标题 / 状态板 / 页脚、README、CHANGELOG、考据、计划、登记、资产清单、压缩包名。
- 每次交付固定：**游戏 HTML + Markdown 文档 + 压缩包**。
- **v0.14 起立为硬规则**：每轮固定生成素材，不需要用户提醒 —— 找下一批缺口 → 生成 → 抠图验收 → 接进网页 → 解锁对应关卡 → 更新六份文档。写进 README、CHANGELOG、生成计划与缺口登记，每轮对照执行。

## v0.14 — 2026-11-08 · 极简开始 / 小判读 / 幽灵修复 / 按钮零遮挡 / 固定生成素材

### 用户反馈

> 「主页还是太多东西了，开始都看不到不醒目，哈士喵的判读气泡太大了吧，上条当麻cos怎么透明了看起来跟幽灵似的，上轮没提醒忘了生成素材，我下轮不提醒了，每轮请记得生成素材，换个方向和退出横屏有盖住东西吗」
> 附两张手机截图：主页被长文和卡片占满；横屏反馈态里「判读」长条盖半屏、角色发虚、两个按钮挤在 HUD 旁。

### ① 主页首屏只剩「开始」

- `#home` 重构：`home-cta`（金色大按钮 + 一行副标题 + 一行进度）+ 一个默认收起的 `<details>`（玩法长文 / 三步卡 / 难度 / 资料规模 / 角色预览）；
- 大按钮 82px 高、22.7px 字、金色渐变 + 外发光；手机再把 masthead 状态板隐藏、标题压成一行（36px 高），按钮 top **248 → 189px**；
- 所有原 id 保留，`startBtn` 点击仍读 `#diff` 并进关卡地图；按钮小字随存档显示「继续 · 已通 N / 30 关」。

### ② 「哈士喵的判读」小气泡

- 不再复用底部选项大条 `mode-choice`（60% 宽 / 37% 高），改独立 `mode-feedback`：38% 宽 / 32% 高（手机 66% / 30%，横屏 34% / 36%），实测占屏 38%×16%；
- 去掉 `backdrop-filter`，避免把气泡后面的角色糊成一片；底 `.54/.62` + 文字投影保可读；
- 「↩ 回到对白」从控制条收进气泡内；`vnRender` 包装在回到对白时清掉 `mode-feedback` 与 `feedback-mode`，不残留。

### ③ 上条当麻 cos「像幽灵」的两个根因

| 根因 | 原状态 | 修复 |
|---|---|---|
| 双帧呼吸 `ease-in-out` 交叉淡化 | 25% / 75% 时刻 A、B 各 `opacity .5`，两张略错位图叠成重影＋半透明 | **硬切**：`0–49.9%` 只显示 A，`50–100%` 只显示 B；采样 14 次恒定 `[1,0]` |
| 选项阶段副角色被压暗 | `.24`（sub）/ `.20`（sub2），上条正是副角色 | `.86` / `.76`，半身 `.90`，反馈态全部 `1` |

新增 `.expr-static`：表情差分静态层关掉双帧动画，只显示一帧，不产生第三重重影。

### ④ 横屏按钮：之前确实盖住，现在 0 重叠

v0.13 实测按钮为 82×32 文字条，位于 `[752,159]` / `[752,199]`（手机设计态 844×390）：退出盖住章节 HUD、换方向盖住天气 HUD，两个都落在角色盒子里。

v0.14 改成 **36×36 纯图标小圆钮**（↩ / ⟳）竖排贴最右边缘，并给角色右侧留 5% 安全带：

| 视口 | 按钮坐标 | 角色右边界 | 重叠项 |
|---|---|---|---|
| 手机 844×390 | `[804,155]` / `[804,199]` | 802 | **0 / 10** |
| 桌面 900×1280 | `[860,600]` / `[860,644]` | 855 | **0 / 10** |

10 项检查：HUD、章节名、天气、剧透标签、对白气泡、题干、名牌、选项控制条、主角色、副角色。换方向后同样 0 重叠，四选项正向 / 换方向都 4/4。

### ⑤ 每轮固定生成素材（本轮 5 张 → 10 层）

先澄清：v0.13 生成了 6 张场景板，但一直欠着的「角色表情／姿态差分」没做，用户的感觉是对的。这版起把生成写成硬规则，不再依赖提醒。

| 最后之作歪头好奇 / 白井得意挑眉 | 1 | 2 层 |
| 麦野冷笑 / 神裂锐利握刀 | 1 | 2 层 |

- `抠图报告_v014_表情.json`：10 层 `alpha_holes` 全部 = 0，大凹陷 / 品红残留达标，亮青底无溢边；
- `ART.expr` + `applyExpr()` 按 `questCast` 逐角色替换立绘，第 4 / 5 / 6 关各 2/2 命中；
- `PERF_READY=[1,2,3,4,5,6]`，**第 4–6 关解锁**，锁关 **27 → 24**；第 7–9 关场景板已入库但仍缺角色差分，继续锁，不假装完成。
