## 一、这版回答了什么

用户要求：「游戏朗读默认关闭，Avg 游戏文字都在画面上，有气泡框，场景也有下雨，太阳啥的动画，天晴有鸟叫声等等，整个 ui 改动一下，避免角色裁剪要完整露出。」

| 要求 | 对应实现 | 归属 |
|---|---|---|
| 朗读默认关闭 | `speakOn=false`；工具栏「🗣️ 自动朗读：关（点按开启）」；「🔁 朗读本句」按需 force 朗读 | 交互默认值 |
| AVG 文字在画面上 + 气泡框 | `renderQuest()` 重写为 16:9 `.vn` 舞台 + `.vn-dialog` 气泡 | 表现层 |
| 下雨 / 太阳等动画 | `WX` Canvas 引擎，7 种天气 | 程序生成 |
| 天晴鸟叫等音效 | `AE.amb` Web Audio 合成 | 程序生成 |
| 整个 UI | 深蓝剧院主题 CSS | 表现层 |
| 角色完整露出 | `object-fit:contain` + 布局分区 | 表现层 |

**没有改动任何剧情事实**：30 关文本、152 词条（人物 64）、61 时间节点、23 部跨媒体、16 题人格测试全部原样保留。

## 二、场景天气与音效：全部程序生成

| 天气 | 画面 | 声音（Web Audio 合成） |
|---|---|---|
| ☀ 天晴 `sunny` | 暖金径向太阳光晕、12 道旋转光束、34 个浮光点、3 只 V 形飞鸟缓慢横飞并扇翅 | 三连频率滑音啁啾（2100→2550→2280 Hz）+ 偶发微风带通噪 |
| 🌧 下雨 `rain` | 150 条斜雨丝、底部 7 处涟漪、随机白闪闪电 | 高频雨滴（900–1850 Hz 下滑至 340 Hz）+ 低通噪声 |
| 🌙 夜晚 `night` | 95 个闪烁星点、1 条斜向流星 | 三连三角波虫鸣（4200 Hz 起）+ 偶发风 |
| ❄ 下雪 `snow` | 110 片正弦摆动雪粒缓降 | 带通风噪 |
| 🌹 红雪 `redsnow` | 同上改粉红 + 底部暗红渐变 | 带通风噪 |
| 🌫 起雾 `fog` | 7 条水平漂移半透明雾带 | 88 Hz 低鸣 + 长风噪 |
| 🍃 起风 `wind` | 46 条气流线 + 5 片旋转落叶 | 带通风噪 |
| ⏹ 静止 `off` | 清空画布 | 停止环境音 |

- 动画：纯 Canvas 2D + `requestAnimationFrame`，按 `devicePixelRatio`（上限 2）缩放，每帧自动 pick 当前可见舞台画布，切页零配置。
- 音效：振荡器 / 噪声缓冲实时合成，独立 `AE.ag` 增益总线（.17），随机间隔递归调度，不加载任何音频文件，离线可用；「🔊 音效」总开关仍生效。
- 音频解锁：首次 `pointerdown` / `keydown` 一次性 `AE.init()` + `ctx.resume()`，符合浏览器自动播放策略。
- **不含任何原作音频、插画或文本素材**。

## 五、对白文本来源

气泡里的所有文字都来自 v0.01 起的**自有导览文案**，按如下规则拼装，不引入原作原文：

- `brief`（发生了什么）按句号拆成 2 句，说话人「哈士喵」；
- `goal`（本关目标）+ `src`（出处）→ 说话人「导览员」；
- `tips`（读图卡）→ 幼喵难度自动追加，其他难度点「🐾 读图卡」叫出；
- 四个 `choices` 与 `why`（解析）→ 选项阶段进气泡；
- 通关后追加「结业馆长」一句回顾。

`aria-live` 隐藏节点写入的是**完整句子**，打字机只是视觉效果（`aria-hidden`），读屏不会逐字重复。
