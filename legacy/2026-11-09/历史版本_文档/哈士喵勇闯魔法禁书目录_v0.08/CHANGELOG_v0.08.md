## v0.08 — 2026-11-07 · AVG 视觉小说模式

### 用户要求

> 「游戏朗读默认关闭，Avg 游戏文字都在画面上，有气泡框，场景也有下雨，太阳啥的动画，天晴有鸟叫声等等，整个 ui 改动一下，避免角色裁剪要完整露出。」

### 逐条落地

| 要求 | 实现 |
|---|---|
| 朗读默认关闭 | `speakOn` 默认 `false`；按钮「🗣️ 自动朗读：关（点按开启）」；`pageSpeak()` 切页静默。新增「🔁 朗读本句」手动读当前对白（force 绕过开关），非剧情页读本页摘要 |
| AVG 文字在画面上 + 气泡框 | 剧情关重写为 `16:9` 视觉小说舞台：`.vn` 容器、背景板、天气层、角色层、HUD、左下 `.vn-dialog` 气泡（人名牌 / 小三角 / 打字机 / 玻璃底）。`brief → goal → src → tips → 四选项 → 答题反馈 → 通关回顾` 全部进气泡；章节 / 剧透 / 天气 / 解锁词条做成 HUD 与紧贴舞台的 `.vn-strip` |
| 下雨、太阳等动画 | Canvas 2D 逐帧 7 种：晴（太阳径向光晕 + 旋转光束 + 浮光 + 3 只扇翅飞鸟）、雨（150 斜雨丝 + 涟漪 + 闪电）、夜（95 星点 + 流星）、雪、红雪、雾（漂移雾带）、风（气流线 + 落叶）。`WX_MAP` 按 30 关卷次氛围自动映射 |
| 天晴鸟叫等等 | Web Audio 实时合成：晴＝三连频率滑音啁啾 + 微风；雨＝高频雨滴 + 低通噪；夜＝虫鸣三角波；雪 / 风＝带通风噪；雾＝88Hz 低鸣。独立 `AE.ag` 增益总线，随机间隔递归调度，⏹ 静止全关 |
| 整个 UI 改动 | 全站深蓝剧院主题：冷蓝面板、暖金描边、玻璃气泡、影院暗角；卡片 / 标签 / 选项 / 节点 / 资料库 / 人格测试 / 弹窗统一深底浅字；工具栏新增「🌤 场景」9 项下拉（自动 + 7 天气 + 静止） |
| 角色不裁剪 | `.vn-char` / `.stage-char` / `.char-btn img` / `.roster img` 一律 `object-fit: contain` + `object-position: bottom center`；主立绘 `height:80% / max-width:42%` 靠右、配角左上错位；气泡 `width:52%` 与角色区不重叠。浏览器实测立绘 boundingRect 全部落在舞台内 |

### 关卡里终于有角色了

按 `v0.06_规划包/30关配图总表` 的出场关系，新增 `CAST_MAP`：每关从已有 21 个透明层里取 **1–3 个角色**登台（1 关茵蒂克丝 + 上条、9 关滨面 / 麦野 / 垣根、24 关茵蒂克丝 / 美琴 / 食蜂…）。`vnCastHtml()` 给主立绘 / 副立绘不同尺寸与错位，alt 写明角色此刻的表情与动作。

**仍未做**：14 张共用场景板、约 29 个新角色、约 27 组关卡姿态 —— 本版复用收拢式定妆层，不新画图。

### 工程要点

- **后定义覆盖**：新 CSS 追加在 `</style>` 前、新 JS 追加在 `</script>` 前；`function renderQuest()` / `function choose()` 后定义覆盖 v0.07 同名函数，数据与存档零改动。
- **天气画布多实例**：开场 `homeStage`、角色舞台 `mainStage`、剧情 `vnStage` 各有一张 `.vn-fx`；`WX.pick()` 每帧找当前可见画布并自动切换，切页无需手动刷新。
- **修过一个实测 bug**：初版把 canvas context 缓存在 `WX.cx`，开场页先建 context 后，剧情页画布始终没像素（检测 `nonAlpha=0`）。改为每帧 `c.getContext('2d')` + 切画布时清空缓存，现 7 种天气像素全部正常（晴 288k / 雨 671k / 夜 671k / 雪 2.9k / 红雪 667k / 雾 164k / 风 5.6k / 静止 0）。
- **反馈不重建选项**：`vnFeedback()` 只改名牌与正文、在控制区前面插入「↩ 回到对白」，四个 `.vn-choice` 保留在 DOM，答错 1.6 秒后可继续点。
- **无障碍**：气泡完整文字写入 `.vn-full`（`aria-live="polite"`），打字机 span `aria-hidden="true"`；canvas 全 `aria-hidden`；`prefers-reduced-motion` 时天气只画静态一帧、打字机直接全文；打印样式回浅色。
- **音频解锁**：首次 `pointerdown` / `keydown` 一次性 `AE.init()` + `ctx.resume()`，符合浏览器自动播放策略。
