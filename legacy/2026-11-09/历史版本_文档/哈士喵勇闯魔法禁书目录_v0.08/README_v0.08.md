## 二、怎么玩

1. 解压 `哈士喵勇闯魔法禁书目录_v0.08.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.08.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」→ **点画面 / 空格 / 「下一句 ▶」** 推进对白；「⏭ 跳到选项」直接答题；「🐾 读图卡」随时把提示叫进气泡。
3. 工具栏「🌤 场景」：默认**自动（随关卡）**，可手动指定天气试听鸟叫 / 雨声；选「⏹ 静止 / 静音」关掉动画与环境音。
4. 音频受浏览器自动播放策略限制：**首次点按任意处**后天气音才响；「🔊 音效」可总开关。

**无障碍**：对白完整文字写入带 `aria-live="polite"` 的隐藏节点，打字机视觉层 `aria-hidden`，读屏不会逐字重复；天气 canvas 全部 `aria-hidden`；`prefers-reduced-motion` 时天气只画静态一帧、关闭打字动画；打印样式自动回浅色；键盘 1–4 选项、空格推进、`R` 朗读、`S` 停读保留。

## 五、技术实现（不依赖外部资源）

- **天气动画**：纯 Canvas 2D + `requestAnimationFrame`，按 `devicePixelRatio` 缩放；每帧自动找当前可见舞台画布，切页零配置；7 种粒子系统（雨滴 / 雪花 / 星点 / 雾带 / 风线 / 光斑 / 飞鸟）。
- **场景音效**：Web Audio 振荡器 + 噪声缓冲实时合成，独立 `ambient` 增益总线，随机间隔递归调度；不加载音频文件，离线可用。
- **对白系统**：`buildDialog()` 把 `brief / goal / tips / src` 拆成 3–6 句，绑定说话人；`vnNext / vnSkipAll / vnTip / vnFeedback` 管理状态；反馈与回顾都在气泡内，不重建选项 DOM。
- **不裁剪**：`.vn-char`、`.stage-char`、`.char-btn img`、`.roster img` 一律 `object-fit: contain`；只有背景板用 `cover`。
