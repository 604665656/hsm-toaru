# 开源成熟方案借鉴与落地 · v0.35

结论：**不换引擎**，继续单文件 HTML + 每轮增量补素材。本轮沿用已落地的工程约定，未引入第三方代码。

| 借鉴 | 已落地 | 本轮复用 |
|---|---|---|
| WebGAL `background/` 与 `figure/` 分层、`changeFigureDiff` 只换差分 | `LAYOUT_RULES.layers` + `applyExpr()` 只换 src 不换位置 | 13–17 关差分接入，立绘位置零改动 |
| Konva `fitContain()` / PixiJS Layout `objectFit` | `fitBox()` + `MutationObserver` 自动套用分层规则 | 新增 4 张场景板仍 `cover`、角色仍 `contain` |
| Ren'Py `zorder` / interact.js `restrictRect` | `LAYOUT_RULES` 声明式边界 | 解锁 5 关后回弹规则未触发，零溢出 |
| W3C Pointer Events / Phaser 输入 | 小游戏鼠标·触屏·触控笔统一事件流 | 逻辑未改，实测 5/5 |
| WCAG 2.5.7 | 键盘 + 💨 按钮单指针替代路径 | 保留 |
| Bun Standalone HTML / silos-packer | 全内嵌零外部依赖 | 7.07 MB，APP 内文件卡片直接可开 |

## 本轮新增经验
**「只加差分索引，不重画角色」是增量项目最稳的推进方式**：已有 17 个定稿差分覆盖 13–17 关全部登场角色时，扩 `EXPR_QUESTS` 比重新生成 6 张角色图风险低得多——历史多轮证明 AI 重画角色会出现脱衣、画风漂移、漏角色、水印。

**「末尾最后生效」要主动利用**：`SCENE_MAP` 在文件多处被赋值（前置常量、v0.18 段、v0.20 段、v0.34 段），新增映射统一放在末尾，避免被前段覆盖；上一轮吃过「末尾覆盖层把字典改回去」的亏，这轮反过来用它保证生效。

## 选型（若将来立项）
Web 优先 → WebGAL（MPL-2.0 + Terre）；重逻辑 → Ren'Py；MIT + PWA → Monogatari。当前增量迭代迁移成本远大于收益。
