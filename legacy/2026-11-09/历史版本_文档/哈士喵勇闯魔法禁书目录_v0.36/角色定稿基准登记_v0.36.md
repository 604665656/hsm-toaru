# 角色定稿唯一基准 · v0.36

**唯一基准 = v0.06 的 21 张角色层**，原样留档在 `美术资产/定稿层_21张_原始留档/`。

- v0.36 **零新画角色、零羽化、零毛边、零描边**：本轮只生成 UI 贴片与场景板
- 点击反馈的角色身份、衣服、道具全部沿用定稿，避免再次出现脱衣 / 画风漂移 / 漏角色
- 17 关实测角色最小安全边 72px、贴边关 0、舞台溢出 0px（继承 v0.34 全量扫描成果）

## 差分硬规则
1. 只在定稿基准上图生图，禁止整批重画
2. 单一纯品红幕、实心闭合、无夹缝、身上无品红像素
3. 色相键控 → 最大前景域 → `binary_fill_holes` → 去色溢
4. 孔洞 `>8` 与 `>128` 都 = 0、无水印
5. **禁止对完整贴图做羽化 / 毛边 / 描边修补**；边缘问题先查 `object-fit` 与容器比例
6. 任何批量替换贴图必须全量扫描所有出现处，末尾覆盖层会写回旧值
7. 已有差分能覆盖登场角色时，优先扩索引而非重新生成
8. 改显示源前先查末尾覆盖层；显示类修复跑多视口矩阵
9. 多角色合版用确定性拼版，AI 只用于单主体、小改动
