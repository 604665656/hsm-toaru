# 开源成熟方案借鉴与落地 · v0.36

结论：**不换引擎**，继续单文件 HTML + 每轮增量补素材；本轮沿用已落地约定，未引入第三方代码。

| 借鉴 | 已落地 | 本轮复用 |
|---|---|---|
| WebGAL `background/` 与 `figure/` 分层 | `LAYOUT_RULES.layers` | 贴片层 / 气泡层 / 立绘层互不影响 |
| WebGAL `changeFigureDiff` 只换差分 | `applyExpr()` 只换 src | 角色层零改动 |
| Konva `fitContain()` / PixiJS Layout | `fitBox()` + 自动分层 | 贴片 `object-fit:contain`，场景板 `cover` |
| Ren'Py `zorder` / interact.js `restrictRect` | 声明式边界 + 候选位最小重叠 | 点击气泡避开 HUD/对白/选项、左右钳制 |
| W3C Pointer Events / Phaser 输入 | 小游戏与立绘统一事件流 | 包装 `poke18`，保留原手势 |
| WCAG 2.5.7 | 键盘 + 单指针替代路径 | 读屏靠 `aria-live`，不占 TTS |
| Bun Standalone HTML / silos-packer | 全内嵌零外部依赖 | 7.3 MB，APP 内文件卡片直接可开 |

## 本轮新增经验
**「组件互斥」不要用单条规则硬判，用候选位 + 最小重叠面积择优**：半身构图里角色贴顶，「重叠就往上抬」会把气泡顶进 HUD；改成 11 个候选位置逐个算与所有禁区的重叠面积，选 0 重叠且最靠近角色的，就同时满足「上下不限、左右不越屏、组件互斥」。

**接口要留得能直接用**：语音包不止给一个 `import` 按钮，而是暴露 `register/play/on/miss` 这类可被后续定制音源接管的钩子，且明确「无片段静默」，避免默认状态触发任何自动播报。
