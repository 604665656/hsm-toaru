## v0.09 — 2026-11-07 · 静音修复 / 主页重做 / 选项不遮挡 / 全屏横屏

### 用户反馈（两张截图）

> 「我点天气预览听下，怎么会自动播报声音，这个主页好丑啊」
> 「这个怎么也会自动读出来，然后画面基本遮挡了，也没有横屏按键」

### ① 自动播报：根因是 `toast()` 强制 TTS

`toast(m)` 里写死 `speak(m,true)`，`force=true` **绕过朗读开关**；`announce(m)` 也无条件 `if(!booting)speak(m)`。因此朗读按钮虽显示「关」，切天气、答题、通关、切全屏等任何提示条都会用系统 TTS 念出来。第二张截图的选项画面同样命中这条链路。

**修复**：
- `toast()` 删掉强制 TTS，改为纯视觉；
- `announce()` 改为 `if(!booting && speakOn)` 才发声；
- 朗读关闭 = **全站零 TTS**。仅「🔁 朗读本句」与「🗣️ 自动朗读：开」会发声；
- 盲人友好不受损：`#live` / `#alert` 的 `aria-live` 仍把文字交给读屏软件，不与 TTS 抢通道；
- 用户想听的鸟叫 / 雨声属 Web Audio 合成场景音，保留且正常响。

**实测**：Hook `speechSynthesis.speak` 计数，跑完「点天气 → 剧情 → 对白 → 选项 → 答题 → 全屏 → 10 页回归」全链路，**触发 0 次**；切晴天环境音 `alive=true / sunny`，晴天画布 61,804 非透明像素。

### ② 主页重做

- `#bgArt` 的三角 / 菱形符文**全部移除**，只留极淡圆点阵，透明度 0.30 → 0.10；
- 新增杂志封面式 `.masthead`：金边头像 + 英文小 kicker + 单行主标题（副标题缩成一句）+ 金色竖线；右侧 `VERSION / 关卡进度 / 已解锁词条 / 当前难度` 状态板，对齐、数字等宽；
- 开场三步玩法 → 3 张编号卡；大块警示框 → 一行脚注；难度 option 文案缩短避免截断；`#homeScale` 字号收紧；
- 工具栏新增金色「⛶ 全屏 / 横屏」，次要按钮加 `.ghost` 弱化。

### ③ 选项遮挡 + 横屏按键

**根因**：4 个长选项竖排在 `width:52%` 气泡里且**没有限高**，气泡从底部长到顶部 → 盖住 HUD、角色只剩半张脸、顶部「读图卡 / 重看对白」被裁出画面。

**修复**：
- 选项 / 反馈阶段气泡切 `.mode-choice`：`width:57%`、`max-height:37%`、`overflow-y:auto`、四选项 **2 列网格**、字号收紧；
- 说话人名牌由 `position:absolute;top:-15px` 改**气泡内一行**，不再被 overflow 裁掉；
- 右下角浮动按钮组 `.vn-corner` **移除**（原会压到角色脚），全屏入口并入气泡工具行；
- 几何实测：`overlapHUD=false`、`overlapChar=false`、气泡与角色间隙 **26px**、名牌完整在气泡内、气泡完整在舞台内；
- **新增全屏 / 横屏**：`goFull()` 调 `requestFullscreen()` + 尝试 `screen.orientation.lock('landscape')`；入口 3 处（工具栏 `#fullBtn`、对白气泡、选项气泡）；CSS `.vn:fullscreen` 铺满视口；竖屏 HUD 显示「📱 建议横屏 · 点 ⛶ 全屏」；语音「全屏 / 横屏」通过包装 `handleVoice` 生效；`Esc` 退出。

### 其他修正

- 「↩ 回到对白」改为 `vnStep=0;vnRender()`，真的回到第一句而非停在选项；
- `goFull()` 目标只选**当前可见**舞台（`$$('.vn,.stage').find(x=>!x.closest('.panel[hidden]'))`），不会误抓隐藏页的元素；
- 选项气泡宽度先从 60% 收到 57%，消除与角色 7px 擦边；
- 打印样式保留 `.masthead` 浅色回退，隐藏横屏提示与浮动按钮。
