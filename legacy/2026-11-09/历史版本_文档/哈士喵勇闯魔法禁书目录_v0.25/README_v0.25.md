## 本轮做了什么
- 你截图里第 9 关那只「只有一片翅膀」的猫，其实是 **垣根帝督（未元物质）**，不是一方通行。他 v0.06 定稿本来就只有一片白翼。
- 以定稿为唯一基准图生图，**只补出左右对称的另一片白翼**，脸 / 圆黑框眼镜 / 深灰斗篷 / 冷峻表情 / 双爪 / 卷尾 / 厚涂彩铅画风一律不动。
- 新层登记为「第 9 关双翼差分」，接入 `ART.chars.kakine` 与 `ART.expr.kakine` 三处；原单翼定稿完整留档，可随时回退。
- 一方通行定稿本来就是 **黑翼＋白翼** 一对，未改动，可在展柜 / 第 29 关看到。
- 副角色舞台份额 20% → 27%，双翼不被压成一小条。

## 抠图验收
纯品红幕 → 色相键控 → 边缘连通背景 → 最大前景域 → `binary_fill_holes` → 内部品红残点最近邻填补。
终层 437×430：`alpha 孔洞 = 0`、品红残留 `0.0001`、前景连通域 `1`、亮青底无溢边。

## 操作
- 剧情页「🖼 看全场景」＝纯净场景开关，再点一次回来
- 「⛶ 横屏」＝ CSS 伪横屏，需手动把手机横过来；方向反了点「↻ 换个方向」
- 设置浮层：气泡透明度、音量、震动反馈、立绘缩放都可调；✕ / Esc / 点遮罩都能关
- 展柜缩略图点开可拖动、缩放、⛶ 全屏；作者原稿按钮全站 0 个
