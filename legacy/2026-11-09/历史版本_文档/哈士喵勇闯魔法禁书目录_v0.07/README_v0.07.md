## 一、先回答你的问题

**「干净了，但是预览图为啥人物没有全图，少了一块？」**

不是抠图又坏了，是**展示层被裁切**。

v0.06 交付的对外预览图全是**极端长宽比的检查图**：

| 文件 | 尺寸 | 比例 |
|---|---|---|
| 新旧对比 | 1500×386 | 3.9 : 1 |
| 21 角色总览 | 960×1766 | 0.54 : 1 |
| 亮青底验收 | 920×1702 | 0.54 : 1 |
| 统一背景合成预览 | 1400×788 | 1.8 : 1 |

APP 文件卡片预览会按接近 **1:1** 居中裁切。长图只剩中间一段 → 人物被拦腰截断，看起来「没有全图、少了一块」。包内 `美术资产/质量检查/预览裁切模拟_根因.png` 就是这四张图按 1:1 裁切后的模拟结果。

### 逐张复核：角色本身没少

| 检查项 | 结果 |
|---|---|
| 21 个透明层四边 alpha（贴边即被切） | 左 / 右 / 上 / 下 **全部 0** |
| 分格线 ±12px 处前景像素密度 | 10 张合页共 11 条分格线，**全部 0%**（没切到角色身上） |
| 最大连通域之外的独立块 | 丢弃的大域（>500px）**0 个**，翅膀／发卷没被丢 |
| 网页舞台（一方通行实例） | 完整全身，黑翼白翼、脚、卷尾全在 |
| 网页角色卡 21 张 | 全部完整全身，`object-fit: contain` |

所以「少了一块」发生在**预览卡片裁图**，不在抠图，也不在网页。
