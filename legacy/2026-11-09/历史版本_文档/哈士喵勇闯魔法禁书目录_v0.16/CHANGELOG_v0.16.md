### ① 人格测试「完全点不动」：真 bug + 两个连带启动崩溃

| 层 | 根因 | 修复 |
|---|---|---|
| 1 | `answerQuiz()` 里 `qh.push({q:q,...})`，`q` 只是 `renderQuiz()` 的局部常量，点击抛 `ReferenceError: q is not defined` | 改为 `DATA.quiz[qi].q` |
| 2 | `perfLocked` 是后定义的 `const` 箭头函数，`renderMap()` 在启动早期调用 → `Cannot access 'perfLocked' before initialization` | 改成 `function perfLocked(id){...}`（声明提升） |
| 3 | `PERF_READY` / `SCENE_MAP` / `QUEST_FRAME` / `EXPR_QUESTS` 是脚本后段的 `const`，启动末尾 `renderAll()` 触发 TDZ → 整段初始化中断，人格测试 / 地图 / 关于页全空白 | 四个常量前置到 `<script>` 开头（先删原位再插头部，避免误删副本） |

实测真点击 16 题 → `qi=16`、结果页「🫶 羁绊守护型」、`qh` 16 条均含题干；重测重置回 4 选项；桌面与手机都能点。

### ② 关卡地图：矮卡 + 已完成折叠到底部

- `.node` 去掉 `min-height:138px` 改自适应，双列网格、出处单行省略、标签缩小；
- 已通关关卡统一收进页面**最底部** `<details>`「✅ 已完成 N / 30 关 · 点击展开回看」，**默认收起**；
- 删掉与新 `map-intro` 重复的旧说明段；
- 桌面 1206px / 手机 2018px（两列 173px）；已通关 3 关时折叠展开恰好 3 张全标「已通关」。

### ③ 名牌紧贴气泡 / 横屏不挡

- `.vn-name` 从 `position:absolute; top:-17px` 改为**气泡内第一行** `inline-block`，与文字零距离；
- 隐藏 `::before` 小尖角；
- 横屏气泡降到 20% 底、取消 `backdrop-filter`；名牌字号缩到 .62rem；
- 实测 `position=static`、尖角 `none`、名牌确在 `#vnDialog` 内。

### ④ 竖屏天气不再挡、副角色下移放大

- 竖屏 HUD 强制单行，隐藏卷次/剧透行与「📱 竖屏建议点横屏」提示，天气缩右上角；
- 副角色 `top 8%→20%`、`height 34%→42%`、`max-width 32%`；
- 实测可见 HUD 仅「章节 + 天气」两个标签，与副角色**重叠 0 项**。
