# 呼吸感与表演素材生成计划 · v0.31

## 本轮（每轮第一件事）
1. 先真生成 2 张场景板：清晨薄雾街角、教堂回廊漂浮书页（均 Image2Image / 现有板基准）
2. 两张全部验收通过、全部进网页，无否决
3. 顺带完成多视口矩阵诊断，找到「载入宽高不够」的决定性根因并修复

## 复盘：为什么连续三轮没修好
前两轮都只查「图片本身 / 容器比例 / 显示源」，且**只在 390×844 验收**。
小屏媒体查询恰好把角色高度压到 64%，掩盖了半身模式的 `108%` 溢出。
→ 规则升级：**任何显示类修复必须跑多视口矩阵**（390 / 768 / 820 / 1024 / 1170），并量化「角色底部 − 舞台底部」必须 ≤ 0。

## 硬规则
1. 每轮先补素材，不等提醒；至少一张真生成稿进网页
2. 角色只在 21 张定稿基准上做差分，禁止整批重画
3. 新层：纯品红幕、实心闭合、`binary_fill_holes` 孔洞 0、无水印
4. 容器规则：`top + height ≤ 92%`，舞台 `overflow:hidden` 下角色不得触底
5. 用户明确否决的稿不补同款
6. 缺素材关卡先锁「敬请期待」，登记缺口但不假装完成

把两张新场景板接入第 13–17 关，并补该段表情差分（单张定稿基准图生图）。
