# 呼吸感与表演素材生成计划 · v0.28

## 本轮（每轮第一件事）
1. 先生成 3 张：两张以用户参考图为基准的 4:5 完整卡（Image2Image），一张自由发挥表情合页（Text2Image）
2. 用户否决第三张 → 整张留档、不进网页、不补同款，原因写进 `美术资产/否决说明.txt`
3. 两张卡去水印 → `contain` 放进 4:5 卡 → 内嵌关于页 + 登记展柜
4. 顺带完成「裁切感」检查与 CSS 修复

## 一致性复盘（连续第 3 轮踩同类坑）
凡 **Text2Image 自由发挥**、没挂已有资产作基准图的，画风必漂。
本轮两张挂了用户参考图、画风就稳；被否那张没挂基准、就漂了。
→ 硬规则升级：**角色类生成一律 Image2Image + 基准图**；Text2Image 只用于「纯品红幕道具合页」这类无角色归属的资产。

## 硬规则
1. 每轮先补素材，不等提醒
2. 角色只在 21 张定稿基准上做差分，禁止整批重画
3. 新层：纯品红幕、实心闭合、`binary_fill_holes` 孔洞 0、无水印
4. 生成稿先比对基准，漂移即否决留档；但**至少一张真生成稿必须进网页**
5. 用户明确否决的稿不补同款，先问清要什么再动
6. 缺素材关卡先锁「敬请期待」，登记缺口但不假装完成

## 下轮
若要表情差分，按定稿基准重做；否则补第 13–17 关专属场景板。
