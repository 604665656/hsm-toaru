## 一、这轮修掉的病根

**「游戏内人物立绘拖不动 / 进关又看不到 / 横屏出画框拉不回来」不是阈值问题。**

v0.18 同时存在**两套**立绘拖拽：模板 ⑦-2 的 `actorTF / applyActorTF` 和 v0.18 注入的 `tf18 / applyTF18`。模板那套会在每次对白刷新时调用 `applyActorTF()` 把 `transform` 写成 `translate(0,0) scale(1)`，把另一套刚写好的位移**清零**；两套还各自处理一次滚轮，缩放被平方（实测 1.48²=2.19）。

v0.19 的做法：

- `actorTF` 直接指向 `tf18`，两套渲染都走同一个 `applyTF18()`；
- 坐标改成**舞台比例**（`x*stageW, y*stageH`），伪横屏按旋转逆矩阵换算，退出／换方向不丢位置；
- `transform-origin` 锁脚底，放大时脚不动、向上长；滚轮改 capture 阶段只算一次；
- 每次切关 `ensureVisible19()` 保证人物默认就在看得见的地方，最多 14 步自动往右上微调。

## 二、这轮全部新交互

### 1️⃣ 叠加互斥与自动弹回

| 约束 | 判定 | 违反时 |
|---|---|---|
| 人物不能出场景太多 | 人物矩形与舞台交集 < 55% | 弹回上一个合法位置 |
| 人物不能进气泡太多 | 与任一文字组件重叠 > 人物面积 40% | 弹回 |
| 文字组件互斥 | 任意两个气泡矩形重叠 | 自动上下错开（上下不限） |
| 左右不越屏 | `0 ≤ x` 且 `x + w ≤ 舞台宽` | 拖动时钳死 |
| 上下不限 | `y` 不钳制 | 允许 |

弹回带 `v19-spring` 回弹动画与「🐾 弹回画面里啦」提示；横屏控制条另有「🐾 归位」一键全复位。

### 2️⃣ 人物旁边那个方框

**不是放头像的**，它原本是「导览员 · 禁书目录」**说话人名牌**。这版改成**真头像框**：放当前关卡主役的哈士喵小头像，设置里可切「头像 + 名字（默认）／纯名字／隐藏」。

### 3️⃣ 所有文字气泡可自定义

对白气泡、判读 / 选项条、章节天气条、通关提示卡都支持：

- 「✥ 布局调整」开启后画面上直接**拖把手**移动、拉右下 **◢** 改宽高；
- 设置里「✥ 调整对象」选中后有**宽度 / 高度 / 字号**三条滑块，不开启布局模式也能调；
- 「↺ 复位全部布局」一键回默认。

### 4️⃣ ⛶ 全屏预览

缩略图右上角 **⛶** 或**双击**＝全屏，**当前选中的场景一起铺满**；人物立绘叠在场景上。全屏时**场景层锁定不可拖，只有立绘可以拖**，＋－↺⛶✕ 全在画框内，Esc / ✕ 可退。未解锁素材显示 🔒 第 N 关，不给全屏。

### 5️⃣ 长按 0.55 秒

- 长按**场景空白处** → 「🏙 选择场景（随进度解锁）」，可切任意已解锁场景或「↩ 跟随关卡自动」；
- 长按**立绘中心** → 「😼 选择表情」：默认静态 / 呼吸帧吸 / 呼吸帧呼 / 本关表情差分 / 借用其它差分；
- 角色矩形边缘的透明区算场景，两个面板互相有跳转按钮；移动超过 9px 取消长按，不与拖动冲突。

### 6️⃣ 震动反馈（可开关）

点击立绘按性格分四型，带不同 `navigator.vibrate` 节奏：

| 类型 | 角色举例 | 表现 |
|---|---|---|
| 元气 | 本体 / 导览员 / 最后之作 | 弹跳 ♡「啊呜」+ `[12]` |
| 冷峻 | 一方通行 / 神裂 / 欧提努斯 | 短抖 …「哼」+ `[22,28,22]` |
| 电波 | 御坂美琴 / 食蜂 / 爱丽丝 | 摇摆 ✦「哔哩」+ `[8,8,8]` |
| 温和 | 上条 / 茵蒂克丝 | 弹跳 ！「嗯？」+ `[10]` |

设置里「📳 点击震动」可关；iOS Safari 不提供 `vibrate`，视觉动画仍有效。

### 7️⃣ 场景音效可选 + 随进度解锁

设置「🎧 场景音效」可指定：自动（随天气）／鸟叫／雨声／虫鸣／风声／风雪／低鸣／红雪风／静音。解锁表：
