## 一、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.03.zip`。
2. 双击 **`哈士喵勇闯魔法禁书目录_v0.03.html`**，用 Chrome / Edge / Safari 打开。
3. 不需要联网、不需要服务器：9 张美术图全部以 data URI 内嵌，单独把 HTML 拿走也能正常显示。

首次使用：🎵 音乐、🎙️ 语音控制需点按授权；🗣️ 自动朗读默认开启；👓 剧透显示默认开启；⏱ 限时小游戏可关闭（无障碍不受计时阻挡）。

## 二、这版改了什么

你说得对：**坂田银时的和服、洞爷湖木刀、草莓牛奶是《银魂》的东西，放进学园都市串戏**。v0.02 把「作者给了银时定稿」直接当成「必须落地」，方向跑偏了。v0.03 按你选的方案修正：

- **唯一视觉基准**换回原作者的「眼镜猫」三视图（灰白毛、圆黑框眼镜、蓝眼吐舌、蓬松卷尾）。
- **银时资产全部退役**：只留在「厚涂画廊」的归档区，标注「跨作品画风实验 · 已退役」，不进主线叙事、不做换装、不设为开场形象。原作者定稿图仍随包保留，授权与来源不变。
- **改做魔禁自家换装**：上条当麻风、茵蒂克丝风、御坂美琴风。

### 换装不是换衣服，表情动作跟着角色走

这是本版按你的追加意见重做的关键点。三套初版曾是「同一张吐舌脸换衣服」，已否决并归档在 `美术资产/迭代过程_已否决_3张/`，方便对照。

| 形态 | 表情 | 动作 | 角色依据 |
|---|---|---|---|
| **本体 · 厚涂原设** | 圆眼、吐舌、放松 | 正面站姿，卷尾自然收在身侧 | 本体 Core 记忆点，只留给本体与导览员 |
| **导览员 · 禁书目录** | 保留吐舌，但视线抬向书页 | 一爪指向漂浮书页与符文路径，一爪抱摊开的魔道书 | 剧情导航员 |
| **上条当麻风** | **不吐舌**：八字眉微垂、眼略眯起的无奈苦笑，额角汗滴 | 左爪挠后脑勺，缠绷带的右爪向前摊开，身体前倾重心不稳，不幸护身符晃起 | 「总被卷进事件但还是伸手」 |
| **茵蒂克丝风** | **不吐舌**：眉梢微垂、蓝眼水汪汪睁圆带委屈，嘴微张 | 双爪把魔道书抱紧在胸前，缩肩、身体略前倾，头巾滑到一边，卷尾收拢 | 十万三千本护书本能＋总饿 |

**不可变身份层**：灰白毛、圆黑框眼镜、蓝色大眼、粉鼻、淡粉腮红、尖耳粉内耳、额前白色菱形毛纹、蓬松灰白卷尾、Q 版头大身小、厚涂绘本毛绒质感。换装只改服装、道具使用状态、表情、动作、重心与镜头。

- 哈士喵为原作者原创角色，由原作者授权使用；两张定稿图均由原作者提供。
- 生成图是按定稿特征图生图重绘的 AI 视觉资产，身份层不变、表情动作贴合角色；**不替代原作者定稿**，不含原作文本／插画／音频。

## 七、版本号规则

从 **v0.01** 起每次递增 `0.01`：v0.01 → v0.02 → v0.03 …；重大重制可跳位。每次交付固定包含 **游戏 HTML + Markdown 文档 + 压缩包**，版本号写进标题、状态条、页脚、文档名与 zip 名。存档键沿用 `hm_v001_state`，v0.01 / v0.02 的关卡与词条进度不丢；形象字段由 `cos` 改为 `look`，旧值自动回落到本体。
