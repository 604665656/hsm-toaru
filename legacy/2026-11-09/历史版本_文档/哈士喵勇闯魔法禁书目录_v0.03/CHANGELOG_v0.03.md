# 更新日志 · 哈士喵勇闯魔法禁书目录

## 版本号规则

- 从 **v0.01** 开始，每次交付递增 `0.01`：v0.01 → v0.02 → v0.03 …
- 重大重制可跳位（如 v0.10）；同一轮只出一套文件，不覆盖旧版本目录。
- 版本号必须同时出现在：网页标题 / 顶部状态条 / 页脚、README 文件名、CHANGELOG 文件名、资料文档文件名、压缩包文件名。
- 每次交付固定包含：**游戏 HTML + Markdown 文档 + 压缩包**。

## v0.03 — 2026-11-07 · 方向修正：银时皮退役，改做魔禁换装

### 用户反馈与决策

- 用户指出：坂田银时的和服、洞爷湖木刀、草莓牛奶属于《银魂》，放进《魔法禁书目录》串戏。v0.02 把「作者给了银时定稿」误当成「必须落地」。
- 用户选择：**改做魔禁换装**，银时三视图退为画风基准与画廊档案，不进主线叙事。
- 用户追加：**表情动作要贴合角色进行变化**——换装不能只是同一张吐舌脸换衣服。

### 方向修正

- 唯一视觉基准换回原作者「眼镜猫」三视图定稿（灰白毛、圆黑框眼镜、蓝眼吐舌、蓬松卷尾）。
- v0.02 的银时 COS 页、银时 SVG 立绘（`huskyGinHero` / `huskyGinAvatar`）、全站银时切换**全部移除**；v0.03 从 v0.01 干净基线重建模板，不继承任何银时主推逻辑。
- 银时资产保留在「厚涂画廊」归档区，标注「跨作品画风实验 · 已退役」；原作者定稿图仍随包、授权与来源不变。
