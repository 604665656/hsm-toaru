## 一、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.02.zip`。
2. 双击 **`哈士喵勇闯魔法禁书目录_v0.02.html`**，用 Chrome / Edge / Safari 打开。
3. 不需要联网、不需要服务器；原作者三视图已压缩内嵌进 HTML，单独拿走 HTML 也能看到。

首次使用：🎵 音乐、🎙️ 语音控制需点按授权；🗣️ 自动朗读默认开启；👓 剧透显示默认开启；⏱ 限时小游戏可关闭。

## 二、v0.02 做了什么（最小 MVP）

只跑通一条链路：**原作者定稿 → 网页可见 → 能切换全站形象**。

| 新增 | 内容 |
|---|---|
| 新页面 | 「COS 衣橱」标签页 |
| 原作者设定 | 「银时」三视图定稿（正面 / 侧面 / 背面），压缩内嵌 + 原图随包 |
| 原创 SVG | 「银时风 · 原作者定稿」全身立绘 + 头像 |
| 交互 | 「设为当前形象 / 换回原设」按钮，同步顶部头像、开场立绘、人格测试结果 |
| 语音 | 新增「衣橱」「换形象」指令 |

按你给的定稿特征重绘：天然卷白毛、圆黑框眼镜、蓝眼、吐舌、粉腮红、白交领和服 + 蓝花纹、黑羽织与袴、灰腰带、草莓牛奶盒、洞爷湖木刀、草莓奶油团子挂饰、蓬松大尾。

**刻意不做**（留到后续版本）：多套 COS、随关卡解锁、三视图拆成独立 SVG、COS 专属音效、COS 剧情关卡。

## 四、键盘与无障碍

| 按键 | 作用 |
|---|---|
| `Tab` / `Shift`+`Tab` | 移动焦点 |
| `1`–`4` | 选择题目选项 |
| `R` / `S` | 朗读 / 停止 |
| `M` / `V` | 音乐 / 语音控制 |

COS 切换按钮可键盘聚焦；三视图有完整 alt 文本；当前形象用文字显示而非仅靠颜色；语音可说「衣橱」「换形象」「换回原设」。
