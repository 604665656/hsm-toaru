## 一、这轮做了什么

### 1️⃣ 角色不再完全静态：双帧呼吸

- 以已有品红幕合页为唯一基准，**图生图生成 4 张呼吸合页**（吸气 / 呼气 × 上条＋茵蒂克丝、本体＋导览员）；
- 按你的一页纸规格抠出 **8 个透明层**，`binary_fill_holes(alpha>128) & ~(alpha>128)` **全部 = 0**，大凹陷与品红残留均达标，亮青底无溢边；
- 网页里 4 个角色用**真图两帧交替**（3.4s，胸腔肩线起伏 + 4px 位移），其余 17 个角色用 CSS 微缩放兜底；系统「减少动态效果」自动关动画；
- 完整规格、命名、下一轮批次见 **`呼吸感与表演素材生成计划_v0.11.md`**。

> 踩过并修掉一个坑：双帧容器是空内容 `<span>`，shrink-to-fit 会塌成 0 宽，角色会整个消失。已显式给 `width:42% / 24% / 20%`，现在实测主角色 468px、副角色 267px，完整落在舞台内。

### 2️⃣ 表演未完成的关卡锁住，写「敬请期待」

- 本轮只有**第 1 关**表演完成（横竖场景板 + 4 个角色呼吸帧 + 飘散书页画进场景板），**2–30 关锁住**；
- 关卡地图显示「🔒 敬请期待 · 表演制作中」；点进去是一张说明卡，列出该关还差哪些场景板／姿态／表情／特效，并给三个出口：去玩第 1 关 / 全关文字导览 / 看缺口清单；
- 「⋯ 更多 → 🔓 全关文字导览」可临时解锁全部 30 关的**纯文字／静态层**阅读（不受顺序限制），默认关闭；
- 资料库、时间线、人格测试等仍正常开放。

### 3️⃣ 语音包表演人声：三层，零版权音源

| 层 | 做法 | 状态 |
|---|---|---|
| ① 系统语音分角色 | 导览员 / 茵蒂克丝 / 上条 / 美琴 / 一方通行各有不同 `pitch` / `rate`，开启「🗣️ 朗读」即用浏览器中文语音包扮演 | ✅ 已实现 |
| ② 自备语音包 | 「⋯ 更多 → 🎧 导入语音包」选本地 mp3/wav，按文件名含角色中文名或 id 自动归户；该角色说话时播放对应音频，未导入的回落分角色 TTS | ✅ 已实现接口 |
| ③ 角色定制音源 | 真人／定制配音需授权与音频资产，登记为缺口 H 类 | ⏳ 待授权 |

**朗读默认关闭＝全站零 TTS**；语音包播放时先 `cancel()` TTS，不与读屏抢通道；气泡 `aria-live` 仍把完整句子交给读屏软件。语音包仅会话内有效（不把音频写进存档），刷新需重新导入。绝不含任何原作声优或版权音频。

### 4️⃣ 不够清爽 / 选项显示不全

- **选项从气泡里搬出来**，变成舞台底部**全宽 2×2 独立控制条**，四个选项始终全部可见（桌面 / 手机竖屏 / 伪横屏实测均 4/4）；
- 题干缩成顶部半透胶囊；选项阶段副角色淡出到 24%，不再互相压盖；角色上移，与控制条留 **61px 间隙**，`charInStage=true`；
- **主导航只留 5 项**：开场 / 关卡地图 / 剧情关卡 / 资料库 / 人格测试；时间线 / 跨媒体 / **角色舞台（换卡）** / 厚涂画廊 / 版本设置收进「⋯ 页面」；
- 工具栏主行 6 项，语音控制、朗读本句、停止、剧透、限时、重玩、语音包、文字导览全收进「⋯ 更多」；masthead 更扁、点阵更淡。

### 5️⃣ 背景全屏、竖屏、横屏

- 新生成**横版 16:9 与竖版 9:16 两张场景板**（同一「学园都市阳台夜」，深蓝＋暖金，魔法阵与飘散空白书页，**画面内无任何角色**）；
- 工具栏「🖼 背景」一键把背景 `position:fixed` 铺满整个视口，按 `orientation` 自动换横版 / 竖版；竖屏时舞台拉高到 `74dvh`；
- 伪横屏模式自动切横版场景板，退出恢复原舞台背景；`resize` / `orientationchange` 自动跟随。

### 6️⃣ 新规则：每轮缺素材就顺手生成

用户明确要求「接下去的每轮，只要有缺素材就顺便完成素材生成」。**从 v0.11 起执行**：每轮找下一批 P0 缺口 → 生成 → 抠图验收 → 接进网页 → 解锁对应关卡 → 更新文档与版本号，**不再只登记**。本轮即按此生成了 6 张原图 / 10 个资产，并把第 1 关从「待补」变成「表演完成」。

下一轮（v0.12）建议批次：三泽塾场景板（横＋竖）、史提尔冷笑差分、上条抬右手姿态、火焰／炼金阵特效层、河边实验场 + 电弧层，对应解锁第 2、3 关。

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.11.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.11.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」玩**第 1 关**；其余关卡显示「敬请期待」。
3. 「⛶ 横屏」把舞台横过来（含「↻ 换个方向」）；「🖼 背景」让场景板铺满全屏。
4. 「⋯ 更多」里可展开剧透 / 限时 / 语音控制，也可「🎧 导入语音包」或「🔓 全关文字导览」。
5. 朗读默认关，不会自动出声；「🗣️ 朗读」开启后是分角色音色，「🔁 朗读本句」可手动读。
