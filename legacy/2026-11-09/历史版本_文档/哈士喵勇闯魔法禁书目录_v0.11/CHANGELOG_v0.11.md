## 版本号规则

- 从 **v0.01** 开始每次交付递增 `0.01`：v0.01 → … → v0.09 → v0.10 → **v0.11**。
- 版本号同时出现在：网页标题 / 状态板 / 页脚、README、CHANGELOG、资料文档、计划文档、登记文档、压缩包名。
- 每次交付固定：**游戏 HTML + Markdown 文档 + 压缩包**。
- **v0.11 起新增交付约定**：每轮只要发现缺素材，就顺手生成一批并接进页面，不再只登记。

## v0.11 — 2026-11-07 · 呼吸 / 锁关 / 语音包 / 清爽 UI / 全屏横竖背景

### 用户反馈

> 「角色非完全静态，加上呼吸感图片生成计划，表演未完全完成的关卡先锁住写尽情期待，然后有没有办法用语音包来表演人声呢，不够清爽，界面没办法显示所有选项，设置换卡相关是否可以隐藏，背景也没有全屏竖屏横屏，接下去的每轮，只要有缺素材就顺便完成素材生成」

### ① 本轮真的生成了素材（不再只登记）

| 生成原图 | 张数 | 产出 |
|---|---|---|
| 场景板「学园都市阳台夜」横版 16:9 / 竖版 9:16 | 2 | 2 张去水印 WebP（134.5 / 131.1 KB）+ JPG |
| 上条＋茵蒂克丝 吸气 / 呼气 品红幕合页 | 2 | 4 个透明呼吸层 |
| 本体＋导览员 吸气 / 呼气 品红幕合页 | 2 | 4 个透明呼吸层 |

- 合计 **6 张原图 → 10 个可用资产**，全部内嵌网页并随包；
- 抠图沿用一页纸三道，**8 层 alpha 孔洞全部 = 0**，大凹陷 / 品红残留均达标，亮青底目检无溢边；
- 生成端锁死：纯品红平涂、只改 2% 胸腔肩线起伏、其余像素不变、轮廓完全实心、无透明玻璃反光、无人脸人形；每次都以**同一原合页**为基准，不链式；
- 唯一工程差异：水印只抹右下角矩形，不抹整条右侧列（保护右侧角色卷尾）。

### ② 角色双帧呼吸

- 4 个有帧角色：`.vn-actor` 双 `<img>` 交错 `breathA` / `breathB` 3.4s，交替 opacity + `translateY(-4px) scaleY(1.014)`；
- 其余 17 角色：`.breathe-css` 微缩放兜底；
- `prefers-reduced-motion` 全部关动画；
- **修掉宽度塌陷**：空内容 span 的 shrink-to-fit 会变成 0 宽导致角色整个消失，已显式给 `width:42% / 24% / 20%`；实测主角色 468px、副角色 267px，`charInStage=true`。

### ③ 表演未完成的关卡锁住写「敬请期待」

- `PERF_READY=[1]`：仅第 1 关表演完成；**2–30 关锁定**；
- `renderMap` 包装：锁定节点禁用、图标 🔒、标签「敬请期待 · 表演制作中」；
- `renderQuest` 包装：锁关渲染说明卡，列出该关缺的素材类别 + 三个出口（去玩第 1 关 / 全关文字导览 / 看缺口清单）；
- `openQuest` 包装：锁关 toast 拦截；`state.textMode` 时**绕过原「先完成上一关」顺序限制**，任意关可读纯文字；
- 「⋯ 更多 → 🔓 全关文字导览」默认关；`tab()` 包装：跳到折叠页时自动展开「⋯ 页面」。

### ④ 语音包表演人声

- `VOICE_CAST` 分角色 `pitch` / `rate`：`speak(text,force,who)` 扩展第三参，`speakNext()` 按 `speakWho` 设置音色；
- `voiceAct(name,text)`：优先播 `voicePack[name]` 的本地音频，未导入则回落分角色 TTS；播放前 `speechSynthesis.cancel()`；
- 「🎧 导入语音包」：`input[type=file][multiple][accept=audio/*]`，按文件名含角色中文名 / id 自动归户（`PACK_ALIAS`），`URL.createObjectURL` 会话内有效；
- 对白推进从 `speak(L.name+'。'+L.text)` 改走 `voiceAct`；朗读关闭仍零 TTS；
- about 页新增「🎙️ 人声表演与语音包」卡，写明三层与「不含原作声优／版权音频」边界；
- 语音关键词：全屏背景 / 语音包 / 文字导览。

### ⑤ 清爽 UI + 选项全部可见

- `#vnCtl` **从气泡里移出**，成为舞台直接子元素；CSS 改成底部全宽半透控制条；
- 选项阶段 `.mode-choice` → 2×2 网格、四选项始终全部可见；题干气泡变顶部胶囊；`.choice-mode` 同步到舞台，主角色上移 `bottom:33%`、副角色淡出到 24%；
- 实测桌面 / 手机竖屏 / 伪横屏 **各 4/4 选项可见**，控制条不压 HUD / 角色 / 题干，角色间隙 61px；
- 点控制条按钮不再误触发 `vnNext()`（排除列表补 `.vn-ctl`）；
- 主导航只留 5 项 +「⋯ 页面」，时间线 / 跨媒体 / **角色舞台（换卡）** / 厚涂画廊 / 版本设置收进抽屉；`tab()` 跳折叠页自动展开；
- 工具栏主行 6 项（新增「🖼 背景」），其余 8 项收进「⋯ 更多」；masthead 更扁、点阵 0.055 → 0.035。

### ⑥ 背景全屏 / 竖屏 / 横屏

- `ART.scenes={h,v}` 两张场景板；`#fullBg` `position:fixed; inset:0; object-fit:cover`；
- `toggleBg()` 切 `body.bg-full`，`syncFullBg()` 按 `orientation` + 伪横屏状态选横版 / 竖版；`resize` / `orientationchange` 跟随；
- `bg-full` 下 `.app/.panel/.card` 透明、`.vn-bg` 与暗角隐藏、竖屏舞台拉高到 `74dvh`；
- 伪横屏自动把 `.vn-bg` 换成横版场景板，退出恢复 `ART.bg`。
