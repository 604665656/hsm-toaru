## 四、代码生成的视觉元素（无图片文件）

| 元素 | 生成方式 |
|---|---|
| 双帧呼吸 | `.vn-actor` 两 `<img>` + `breathA` / `breathB` 3.4s 交错 opacity / transform |
| CSS 呼吸兜底 | `.breathe-css` 3.4s `translateY(-4px) scale(1.012)` |
| 全屏背景 | `#fullBg` `position:fixed` + `object-fit:cover`，按 `orientation` 切横／竖场景板 |
| CSS 伪横屏 | `position:fixed` + `100dvh×100dvw` + `rotate(±90deg)`；控制条在容器外 |
| 通透玻璃气泡 / 底部 2×2 控制条 | rgba 渐变 + `backdrop-filter:blur(11px)` + grid |
| 7 种天气 | Canvas 2D 粒子系统 |
| 场景音效 / 分角色 TTS | Web Audio 合成 + `SpeechSynthesisUtterance` 的 pitch / rate |

**角色不裁剪口径**：`.vn-char` / `.vn-actor` / `.stage-char` / `.char-btn img` 一律 `object-fit:contain`、底部对齐；`.vn-actor` 必须显式给 `width`（空 span 的 shrink-to-fit 会塌成 0 宽）。选项阶段主角色 `bottom:33%`，与控制条实测间隙 61px，`charInStage=true`；副角色淡出到 24%。
