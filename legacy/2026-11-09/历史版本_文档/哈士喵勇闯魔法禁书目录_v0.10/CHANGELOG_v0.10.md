## v0.10 — 2026-11-07 · 真横屏 / 通透气泡 / 简洁 UI / 素材登记

### 用户反馈

### ① 横屏：换成不依赖浏览器 API 的 CSS 伪横屏

**根因**：v0.09 用 `requestFullscreen()` + `screen.orientation.lock('landscape')`。iPhone Safari / APP 内嵌 WKWebView 不支持元素级 Fullscreen API，也不允许网页锁定系统方向 → 点击几乎无反应。

**实现**：
- 竖屏手机点「⛶ 横屏」→ `.ls-target` 舞台 `position:fixed`、`width:100dvh / height:100dvw`、`transform:translate(-50%,-50%) rotate(90deg)`，旋转后视觉包围盒正好铺满竖屏视口，内容按横屏排好；
- `body.ls-flip` 切 `rotate(-90deg)`，适配左右两种横屏方向；
- **控制条放在旋转容器外**（`#lsBar`，`position:fixed` 不跟着转），「↩ 退出横屏」与「↻ 换个方向」两个方向都可点；`Esc` / 再点工具栏「横屏」也可退出；
- 桌面横屏仍走标准全屏；全屏失败自动降级伪横屏，保证点了一定可见；
- 包装 `renderQuest`：横屏中答题会重建 `#quest.innerHTML`，重建后自动重新套用 `.ls-target`，不掉出横屏；
- `WX.type=null; WX.setType()` 强制按新尺寸重新 seed 天气画布；
- 伪横屏下气泡 `max-height:76%` + 选项字号收紧，四个选项**全部可见无需滚动**（实测 `scrollHeight === clientHeight`）；
- 进入横屏后隐藏 HUD 的「建议横屏」提示。

**边界**：网页无法强制旋转 iOS 系统状态栏，只能把舞台内容横过来；设备方向锁定时需手动横过手机。已在页面 toast 与 README 如实说明。

### ② 气泡通透

`.vn-dialog` 玻璃底 `#0a1729f4`（≈96%）→ `linear-gradient(rgba(10,23,41,.58), rgba(11,30,53,.66))` + `backdrop-filter:blur(11px) saturate(1.15)`；`.vn-choice` 降到 74% 不透明；小三角同步半透。为保可读：文字双层投影、边框暖金半透。桌面几何复验 `不压 HUD / 不压角色` 仍为 true，间隙 26px。
