## 一、四条反馈，逐条落地

### 1️⃣ 「并没有横屏」

**根因**：v0.09 的横屏按钮调 `requestFullscreen()` + `screen.orientation.lock('landscape')`。iPhone Safari / APP 内嵌 WKWebView **不支持元素级 Fullscreen API，也不允许网页锁定系统方向**，所以点了几乎没反应，只弹一句提示。

**v0.10 改成不依赖浏览器 API 的 CSS 伪横屏**：

- 竖屏手机点「⛶ 横屏」→ 舞台 `position:fixed`、尺寸 `100dvh × 100dvw`、`rotate(90deg)` 铺满视口，**内容已经按横屏排好**；
- 把手机横过来看就是正的；方向反了点「↻ 换个方向」切 `rotate(-90deg)`；
- 控制条放在旋转容器**外面**（不跟着转），所以两个方向都能点：「↩ 退出横屏」/「↻ 换个方向」；`Esc` 或再点工具栏「横屏」也能退出；
- 桌面横屏仍走标准全屏；全屏失败自动降级到伪横屏，**点了一定看得见变化**；
- 横屏中答题会重建 `#quest`，已包装 `renderQuest` 自动重新套用，不会掉出横屏。

> 诚实边界：网页**无法强制旋转 iOS 系统状态栏**，只能把舞台内容横过来；设备方向锁定时请手动把手机横过来。这是浏览器限制，不是按钮坏了。实测 390×844 手机视口：`ls-mode` 生效、`transform: rotate(90deg)`、`position:fixed`、`z-index:120`、退出按钮可点、四选项全部可见无需滚动。

### 2️⃣ 「气泡通明度高一点」

`.vn-dialog` 玻璃底从 `#0a1729f4`（≈96% 不透明）改成 `rgba(10,23,41,.58) → rgba(11,30,53,.66)`，加 `blur(11px) saturate(1.15)`；选项按钮也降到 74% 不透明，背景与角色能透出来。为保可读：文字加双层投影、边框改暖金半透、小三角同步半透。实测 computed `background-image` 与 `backdrop-filter` 均生效，选项仍不压 HUD / 角色（间隙 26px）。

### 3️⃣ 「界面简洁清爽一点」

- **工具栏主行只留 6 项**：音效 / 音乐 / 朗读 / 场景 / 横屏 / 「⋯ 更多」；语音控制、朗读本句、停止、剧透、限时、重玩 6 项收进「更多」抽屉（默认收起）；
- 按钮 `min-height` 40→38px、字号收紧、圆角统一、边框减淡；点击后回写的长文案一并缩短，不再把按钮撑成一行半；
- 手机 masthead 压成**一行标题 + 4 格状态**，隐藏英文 kicker 与长副标题；状态板 `grid 4 列`；
- 背景点阵透明度 0.10 → 0.055，卡片去阴影、边框改半透；
- 手机竖屏实测：主行可见 5 个按钮 + 1 个场景下拉，masthead 从大块压到 142px。

### 4️⃣ 「动画表演缺素材就登记，后续生图补」

**本版不生成任何新图、不重跑抠图、不新增内嵌资源。** 新增包内文档 **`动画表演素材缺口登记_v0.10.md`**：

- **A–H 八类缺口**：姿态差分 / 表情差分 / 14 张场景板 / 特效层 / 天气×表演 / 待机循环 / 转场演出 / 音效分层；
- **30 关逐关表**：每关写清「现在用什么定妆层凑的」「还差什么表演」「后续该补哪张图」「优先级 P0/P1/P2」；
- **21 个角色表情差分需求**逐条列；
- **14 张场景板**覆盖关系（16 与 23 关共用「幸福世界」）；
- **6 批生成顺序**与验收口径；
- 网页「版本 & 操作」页新增可折叠的「🎬 动画表演素材缺口登记」摘要入口。

> 后续补图仍按你的一页纸规格：纯品红实心、身上不留可填充空隙；**展开翼 / 火焰 / 金币雨一律画进场景板或独立特效层**，角色层保持闭合剪影，不重犯 v0.05 开口缝缺块。

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.10.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.10.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」→ 点画面 / 空格推进对白 → 四选一。
3. **手机横屏**：工具栏「⛶ 横屏」→ 把手机横过来 → 方向不对点「↻ 换个方向」→「↩ 退出横屏」或 `Esc` 退出。
4. 「🌤」切天气试听鸟叫 / 雨声；「⋯ 更多」展开剧透、限时、语音控制等次要开关。
5. 朗读默认关，不会自动出声；想听点「🗣️ 朗读」或「🔁 朗读本句」。
