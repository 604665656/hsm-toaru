## v0.13 — 2026-11-08 · 真正全屏横屏 / 透明度分层 / 再补 6 张场景板

### 用户反馈

> 「横屏但是没有完全横屏，背景还有竖着的人格测试等导航，主页还有很多按钮和指示导航，尽可能简洁一点，设置的气泡不够透明，主页的有字的又太透明了已经完全透明字看不清楚了」
> 附手机横屏截图：内容转了 90°，但外围导航仍竖着，且只看见两个选项。

### ① 【核心修复】伪横屏的位移矩阵把舞台推出屏幕

旧写法 `left:50%;top:50%;transform:translate(-50%,-50%) rotate(90deg)`：`translate(-50%,-50%)` 按**未旋转**的 844×390 计算，与旋转叠加后中心跑偏。

实测（手机 390×844）：舞台 `getBoundingClientRect() = [0,-422,390,844]`，整体被推到屏幕上方 422px → **四个选项只有第 3、4 落在视口内**。这就是「没完全横屏」的根因。此前几轮只验「选项在控制条内」，没验「控制条在视口内」，所以一直漏掉。

改用可靠写法，舞台 / 全屏背景 / 横屏控制条**三者共用同一矩阵**：

```css
transform-origin:0 0;
transform:rotate(90deg) translateY(-100%);
/* ls-flip：rotate(-90deg) translateX(-100%) */
```

并加 `max-height:none;aspect-ratio:auto` 解除桌面 `max-height:86dvh` 的钳制。

| 项 | 修正前 | 修正后 |
|---|---|---|
| 舞台 rect | `[0,-422,390,844]` | **`[0,0,390,844]`** |
| 背景 rect | 偏移 | **`[0,0,390,844]`** |
| 控制条 rect | 与舞台不同矩阵 | **`[0,0,390,844]`** |
| 四选项在视口内 | 2 / 4 | **4 / 4**（正向与换方向都通过） |
| 桌面 | 舞台被 clamp 到 774 高 | **铺满 1280×900** |

### ② 外围全部收掉，只剩舞台

- `body.ls-mode .app>*:not(#main){display:none}` + `#main>*:not(#story){display:none}`：标题栏、工具栏、主导航（人格测试等）、其他页面、页脚、设置浮层全部隐藏；
- `.app / #main / #story / #quest` 清掉 padding、边框、圆角、阴影、最大宽度；`.ls-target` 去边框圆角；
- `#lsBar` 用与舞台相同的旋转矩阵，横过手机后「退出横屏 / 换个方向」与对白方向一致；
- 横屏里隐藏多余的「⛶ 横屏」按钮与 `.vn-hint` 键盘提示；
- `openSettings()` 增加守卫：横屏中被语音 / 快捷键唤起时先 `exitLandscape()`，不会冒出竖着的设置面板；
- 手机状态板 4 格收成 **2 格**，masthead 更扁。

### ③ 透明度分三层，不再一刀切

病根：v0.12 为全屏背景写了 `body.bg-full .panel,.card,.step{background:transparent}`，把首页所有带字容器一起清成透明。

| 层 | v0.12 | v0.13 |
|---|---|---|
| 设置浮层 | `#162e49f5` ≈ 96% 实底 | **`rgba(.34/.40)` + blur(18px)** |
| 设置内分组卡 | `.a8` 实底 | **`rgba(.30)`** |
| 设置内按钮 | 实底 | **`.72` 实底**（保字） |
| 主页 / 资料库带字面板 | **transparent** | **`rgba(.93/.91)` + blur(9px)**，标题统一暖金，正文统一浅色 |
| 舞台对白气泡 | `.30/.38` | **`.26/.32`**，文字加第四层投影 |
| 舞台选项控制条 | `.40/.48` | **`.34/.42`** |
| 选项按钮 | `.55` | `.48` |
