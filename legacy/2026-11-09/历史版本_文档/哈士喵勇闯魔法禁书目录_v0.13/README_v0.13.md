## 一、这轮做了什么

### 1️⃣ 「横屏了但没完全横屏」—— 真因找到了

你截图里最刺眼的是：内容转了 90°，但人格测试、设置、背景等导航还竖着挤在边上，而且只看见两个选项。

**根因不是旋转角度，是位移矩阵。** 旧写法：

```css
left:50%; top:50%;
width:100dvh; height:100dvw;      /* 手机上 = 844 × 390 */
transform:translate(-50%,-50%) rotate(90deg);
```

`translate(-50%,-50%)` 的百分比按**未旋转时**的 844×390 算，和旋转叠加后中心跑掉了。实测舞台 `getBoundingClientRect() = [0, -422, 390, 844]` —— 整体被推到屏幕上方 422px，四个选项里只有第 3、4 落在视口内。这就是「没完全横屏」的真相，之前几轮只验了「选项在控制条内」，没验「控制条在视口内」，所以漏掉。

**改成可靠的旋转写法**：

```css
transform-origin:0 0;
transform:rotate(90deg) translateY(-100%);
/* 换方向：rotate(-90deg) translateX(-100%) */
```

舞台、全屏背景、横屏控制条**三者用同一个矩阵**。实测：

| 项 | 修正前 | 修正后 |
|---|---|---|
| 舞台 rect（手机 390×844） | `[0,-422,390,844]` | **`[0,0,390,844]`** |
| 背景 rect | 偏移 | **`[0,0,390,844]`** |
| 控制条 rect | 另一套矩阵 | **`[0,0,390,844]`** |
| 四选项在视口内 | 2 / 4 | **4 / 4** |
| 换方向后 | 未验 | **4 / 4** |

### 2️⃣ 外围全部收掉，只剩舞台

进入横屏时隐藏 `.app` 下除剧情舞台外的一切：标题栏、工具栏、主导航（人格测试等）、其他页面、页脚、设置浮层。画面里只剩 **全屏场景板 + 角色 + 气泡 + 选项 + 「退出横屏 / 换个方向」**。这两个按钮也跟着舞台一起转，横过手机后方向和对白完全一致，不再是竖着的两块。

横屏里多余的「⛶ 横屏」按钮和键盘提示也隐藏；手机状态板从 4 格收成 **2 格**。设置若在横屏中被语音或快捷键唤起，会先自动退回竖屏再打开，不会冒出一块竖着的面板。

### 3️⃣ 透明度分成三层，不再一刀切

你说「设置的气泡不够透明，主页的有字的又太透明了已经完全透明字看不清楚」——病根是我上一版为了全屏背景，写了 `body.bg-full .panel,.card,.step{background:transparent}`，把首页所有带字容器一起清没了。

| 层 | v0.12 | v0.13 |
|---|---|---|
| 设置浮层 | `#162e49f5` ≈ 96% 实底 | **`rgba(.34/.40)` + blur(18px)** |
| 设置内分组卡 | `.a8` 实底 | **`rgba(.30)`** |
| 设置内按钮 | 实底 | **`.72` 实底**（保字） |
| 主页 / 资料库带字面板 | **transparent** | **`rgba(.93/.91)` + blur(9px)**，标题统一暖金 |
| 舞台对白气泡 | `.30/.38` | **`.26/.32`**，文字加第四层投影 |
| 舞台选项控制条 | `.40/.48` | **`.34/.42`** |

一句话：**该透的地方透（设置浮层、舞台气泡），该实的地方实（有字的主页面板）**，文字全部保留可读对比度。

## 二、怎么打开

1. 解压 `哈士喵勇闯魔法禁书目录_v0.13.zip`，双击 `哈士喵勇闯魔法禁书目录_v0.13.html`（Chrome / Edge / Safari，离线可用）。
2. 进「剧情关卡」玩第 1–3 关；其余显示「敬请期待」。
3. 点「⛶ 横屏」→ **把手机横过来**，舞台、背景、控制条都是同一方向；方向反了点「↻ 换个方向」，「↩ 退出横屏」随时回竖屏。
4. 「⚙ 设置」是独立浮层，右上大红 ✕ / 底部通栏 / Esc / 点遮罩都能关，内容可滚动、标题栏可拖动。
5. 朗读默认关，不会自动出声。
